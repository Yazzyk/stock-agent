# 交互与视觉规范（UX）

版本：v1.0 · 2026-11-10 · 对应前端骨架 `frontend/`（Vue3 + TS）

## 1. 设计原则

1. **数字优先**：能用一个数字说清的事，不写一段话。每块内容的第一行是结论，数字带单位与口径。
2. **状态可见**：任何异步数据必须能回答"这是什么时候的、准不准"。不允许无时间戳的行情。
3. **可回退**：所有写操作（同步、保存、运行）先给可撤销入口，不可撤销的要二次确认并说明后果。
4. **不制造压力**：不弹窗催操作、不红色闪烁、不用感叹号。研究工具不该让人焦虑。
5. **一屏一任务**：每个面板只服务一个 job（见 PRD 第 3 节），不堆功能。

├─ 顶栏（面板标题 / 搜索 ⌘K / 数据健康指示灯 / 总体状态 / Agent 输出开关 ⌘J）

│   ├─ 自选 watchlist（行情 10）

## 4. 面板清单

本节同时是设计目标与实现口径；与 `docs/USER-GUIDE.md` 第 3 节不一致时，验收按 USER-GUIDE 与实际界面判定。

### 4.1 自选 watchlist

- **目的**：一屏看完自选股当前状态、资金位置，并一键进入 K 线/资金详情。
- **布局**：顶部数据源状态条 + 同步按钮 + 列设置；下方分组标签 + 表格。表格列：代码 / 名称 / 分组 / 现价 / 涨跌幅 / 成交额 / 换手 / 主力净额 / 主力占比 / 走势（当日分时小图）/ 操作；操作列 sticky 在右侧。
- **同步向导**：4 步（local / web-login / web-capture / manual），每步一个主按钮；授权后自动轮询并续跑；失败时保留手动同步与粘贴入口。
- **主操作**：同步、刷新、列开关、行内「K线 / 分时 / 资金」；点走势小图或「分时」打开当日分时大图（价格/均价/昨收/成交量 + 悬停读数），行点击跳转 K 线且不弹 toast。
- **状态**：空 → 向导 + 同步；加载 → 表格骨架；错误 → 可操作提示；缓存 → 行内「缓存」角标；分时失败 → 走势列显示「—」，不影响表格与其它列。

### 4.2 资金流 fundflow

- **目的**：判断资金在往哪个方向走，以及个股资金是否被板块解释。
- **布局**：板块/概念资金流线（默认净流入 TOP8 + 净流出 TOP8 的多线图）+ 资金排名双榜（主力净流入 TOP / 主力净流出 TOP）。**不再展示个股资金卡**。
- **主操作**：切板块/概念、切 10/20/60 日、点图例隐藏/显示单线、点榜单行加入/移出图线、重置图表、分别刷新两个榜。
- **状态**：加载 → 图表骨架；错误 → 保留上次数据 + 原因；板块多日不可用 → 明确提示「只有当日快照」。
- **口径**：主力 = 超大单 + 大单；15:05 前为盘中滚动值，面板固定标注。两个榜共用当前 kind，净流入用红、净流出用绿；涨跌幅与主力占比列在数据缺失时整列隐藏，不显示误导性的 0。
- **资金流线**：每条线是一个板块/概念的**区间累计主力净额**（逐日 `mainNet` 累加，缺失日沿用前值）；流入板块红系、流出板块绿系。图线右端直接标注板块名称（防重叠），图例显示名称、当日涨跌幅与最新累计值；顶部摘要显示流入/流出 TOP 的名称与涨跌幅。悬停显示日期与最多 6 条读数，其余折叠为「其他 N 条」。最多同时对比 20 个板块。
- **降级**：板块榜与板块多日资金流都只有新浪一条链路（`ssl_bkzj_bk` / `ssl_bkzj_zjlrqs`）；新浪不可达时保留上次数据 + 黄条写清原因，涨跌幅与占比整列隐藏（不显示误导性的 0）。口径是新浪 `netamount` 的板块全部资金净额，不是主力净额，面板与图例按 `source` 标注。

### 4.3 K 线 kline

- **目的**：看位置、量能、结构，给出失效位；从自选/搜索/量化一键进入。
- **布局**：顶部 StockPicker + 周期 seg + 指标开关 + 最新/研判/最大化；自选 chips；OHLC 读数条；主图 + 成交量（可选 MACD 副图）；右侧可折叠研判栏。
- **主操作**：换标的/周期、开关指标、滚轮锚点缩放、拖拽平移、双击复位、键盘 ←/→/+/−/Home。
- **状态**：空 → 提示从自选选标的；加载 → skeleton；错误 → 重试；复权降级 → 底部常驻标注。
- **强制规则**：研判结论只描述结构，不构成买卖建议；复权口径常显。

### 4.4 Watch 哨兵 watch

- **目的**：把「我一直盯着」变成「条件命中才看」。用户声明盯什么，引擎定时求值，命中后派一次 Agent 任务并留下结论。
- **布局**：上方规则列表（列：开关、名称、触发源摘要、条件、最近触发、触发次数）；下方分三块——规则编辑器（基本信息 / 触发源 / 条件 / 动作 / 冷却与静默窗口）、试运行结果、触发日志。编辑器右侧常驻「指标白名单」速查（22 个，按 quote/flow/sector/kline/news/time 分组）。
- **主操作**：从模板新建、保存、开关（toggle）、试运行（test）、删除、查看日志、从模板新建后关着保存（默认 `enabled=false`）。
- **条件输入**：只允许白名单指标 + 比较运算符 + `and/or/not` + 括号。输入时提供指标名补全；写了非白名单标识或函数调用，即时红字提示并禁止保存（不做「先存后报错」）。
- **试运行区看什么**：命中徽标（`matched`）、每个标的/板块一行（名称、关键指标实测值、是否命中）、将要发给 Agent 的 `prompt` 原文、取数耗时。文案必须写清「只求值，不触发 Agent」。
- **日志区看什么**：时间、规则名、worker、指标快照、Agent 结论摘要、错误原因；空时写「还没有触发记录」，不要写「暂无数据」。
- **状态**：
  - 空：`还没有规则。可以从模板新建，或直接告诉 Agent「半导体板块主力净流入超过 20 亿就提醒我」。`
  - 加载：规则列表骨架 3 行；引擎 `running=false` 时顶部常驻横幅 `Watch 引擎未运行，规则不会求值`。
  - 错误：单条规则文件格式非法时，只在该行标记 `规则文件格式非法：<文件名>（<原因>）`，不影响其它规则；整体读取失败才用整块错误态。
  - 过期：不适用（求值实时）。但「最近触发」超过 24 小时要在行尾灰字标出，提示可能是条件过严或引擎未运行。
- **硬约束（文案与交互都要体现）**：
  - 条件只能读白名单指标，**不提供脚本输入框**，不出现「执行」「运行代码」这类字眼；
  - 触发动作只能选 worker + 填 prompt，不能配命令、不能配文件写入路径；
  - 保存前必须通过校验（名称、至少一个触发源、条件可解析、worker 合法），校验失败逐条给出中文原因。
- **实现状态**：已交付（`frontend/src/panels/watch.vue`，研究组 order 35，浏览器验证通过）。落地形态与本节一致：顶部一句话创建 + 从模板新建 / 新建规则 / 刷新，左侧规则列表带开关，右侧编辑器（触发源增删、条件输入 + 指标 chips 插入、保存 / 试运行 / 删除），底部触发日志。
### 4.5 Agent agentlab

- **目的**：以 Agent 为中心：默认和「RouterAgent（router）」对话，由 RouterAgent 拆解任务、分派给 worker 或创建新 worker；同时保留盘前/盘中/复盘自动值班。
- **布局**：顶部**一条紧凑值班条**（盘前 / 盘中 / 复盘：状态点 + 倒计时 + 排期 / 频率 + 自动开关 + 提示词 + 立即运行）+ 模型选择在输入区左下（不在顶部）；左栏 260px（主控卡 / 任务 Worker / 历史会话）；右主区标签「对话 / 轨迹 / 报告 / 上下文 / 编队」；底部浮动玻璃输入区。上下文与编队是**全宽页**，进这两页时左栏收起、输入区隐藏。
- **新建会话**：左栏顶部「＋ 新建会话」与面板头「＋ 新会话」同义——清空当前转写、报告册、上下文与编队，回到 RouterAgent 的空白对话（运行中禁用，先停止）。模型选择在输入区左下，不占标题栏；只影响下一次运行。
- **对话（参考 Pi Agent 桌面端）**：用户消息右对齐琥珀气泡（时间 · 你）；助手消息**不是气泡**——首行给 worker / 模型 / 时间 / 步数 / token，正文用 Markdown，代码块带语言标签与复制；工具调用是助手块里的 **26px 紧凑行**（`工具名 · 参数 → 结果首行 · 耗时`，失败整行红），点击展开完整参数与结果；状态行是极小 chip（思考中带脉冲点，完成后 `×N` 心跳合并）；流式段末有光标；只在「用户原本贴底」时自动跟随，向上翻后右下角出现「回到底部」。空态给 4 个建议 chip（盘前计划 / 盘中异动 / 收盘复盘 / K 线结构）。
- **轨迹（参考 DSH 轨迹）**：32px sticky 工具栏（轮次折叠 / 调用折叠 / 搜索）+ 50px 三泳道密度条（输入 / 模型 / 工具，用户蓝、模型紫、工具琥珀、失败红）+ 账本式表格：行高 30px、左列 84px（轮次竖线 + 「第 N 轮」角标 + 19px 角色标签：用户 / 助手 / 工具 / 状态），工具行按 `名 · 参数 → 结果` 两栏排布、等宽字、单行省略、失败红；用户消息开启新一轮，轮首给可折叠摘要「第 N 轮 · X 步 · Y 次工具调用」；选中行右侧滑出 inspector（角色 / 工具 / 状态 / 耗时 / 开始时间 / 参数 / 结果）；搜索是过滤而不只是高亮；超过 300 行只渲染尾部并提示已折叠行数。
- **报告（多份不覆盖）**：同一会话的多份报告（子任务 + RouterAgent 汇总）以「标签带 + 正文」呈现：顶部 `N 份报告 · 复制当前`，下面一条横向标签带（最新排最前，每个标签显示 `#序号 / worker / 时间 / token` 与「最新」角标），点标签切换正文；正文头显示会话短 id / 步数 / token / 「推理回退」标注。新一轮运行**不清空历史报告**，打开历史会话时整份替换为该会话的报告。
- **编队**：没有子智能体时**只显示一张 RouterAgent 卡**（状态 / 会话 / 步数 / token / 耗时 / 开始时间 + 「打开会话日志」），不再渲染空的三栏；有子智能体时顶部一行 worker 花名册 chips（节点数 + token），下面两栏：谱系树（父子连线、状态点、token、耗时、步数）与节点详情（报告摘要可滚动、按钮常驻）。
- **上下文**：KPI 6 格（已用 / 窗口 / 占比 / 缓存命中 / 步数 / 工具调用）、system/tools/messages 组成环形图 + 4px 堆叠条、**逐轮台账**（步 / 请求 prompt / 缓存命中 / 输出 / 上下文规模 / 时间）、逐轮趋势（优先后端 `history`，为空回退本地采样）、事件流与口径脚注；标题栏另有一枚可点开的小环。口径约定：`pressureTokens` 是提供方上报的最近一次请求 prompt，有它就标「精确」，否则标「估算」并给 `~` 前缀；组成分项只切相对比例，**不与精确占用对账**。
- **Worker 点击**：立即切到该 worker 详情（标题 / 描述 / 模型 / 提示词摘要 / 最近会话），并自动打开最近一次会话；运行中点 Worker 只提示先停止，不打断当前会话。
- **只读约束**：只有「RouterAgent」可以直接对话；盘前 / 盘中 / 复盘 / 量化 / 问答与自定义 Worker 均只能查看详情与历史，任务必须由 RouterAgent 分派，或由值班调度 / 值班卡触发。
- **主操作**：和 RouterAgent 对话、新建会话、新建 worker、删除自定义 worker、切换模型、开关值班、改时间 / 频率、编辑提示词、立即运行、停止、插话、打开子会话、复制报告。
- **RouterAgent**：简单概念问题可直接答；需要行情 / 复盘 / 量化时用 `agent.spawn` 派子任务，没有合适 worker 时先 `worker.create` 再派生；最终汇总子报告。
- **状态**：无模型 → 值班条标「未配置模型」且不触发；运行中 → 上下文环 + 状态点 + 输入区切换为「插话」；失败 → 报告保留 + 可操作错误。
- **日志事件**：`agent.tool` 提供工具调用轨迹（start/end 按 id 合并，乱序不丢行）；`agent.context` 每次模型调用前推一帧、运行结束补一帧；重复的盯盘心跳合并为 `×N`。
- **视觉**：毛玻璃（`backdrop-filter: blur() saturate()` + 半透明层次 + `--glass-1/2/3`）+ 统一圆角（卡片 16 / 控件 12 / 小标签 8）；动效 120–180ms，`prefers-reduced-motion` 关闭闪烁。
- **停机收口**：步数上限（或显式设置的 token 预算）耗尽时，报告页仍会基于已有工具结果生成「结论/依据/不确定性/风险提示」，并在尾部说明停机原因；不会只留一行停机提示。**Token 默认不设预算上限**（`MaxTokensPerRun=0`），默认只会因工具调用步数与模型单次输出上限停机。
- **空回复诊断**：正文为空时报告页给诊断卡（后端 `emptyReason` + `diagnostics`），并给三条可操作动作——「把输出上限调到 8192 后重试 / 换一个模型 / 看轨迹」；不再是一句「模型没有返回内容，请重试」。

### 4.6 量化研究 quant

- **目的**：验证规则在过去是否成立，并让读者知道结论有多可信。
- **布局**：参数区（StockPicker + 周期/策略/参数/资金/折数）+ 可折叠「算法说明」（全局口径 + 当前策略公式/规则/参数范围）+ 8 个指标卡 + 成本行；图表区上下两段：标的 K 线（含 B/S 标记）+ 净值曲线；下方「回测报告 / walk-forward / 参数优化」。
- **主操作**：搜索选股、运行回测、walk-forward、参数优化、让 Agent 自主优化、回撤阴影开关。
- **参数优化**：候选表显示排名/参数/总收益/年化/回撤/夏普/交易数/稳健性，推荐行高亮；报告解释「为什么不是单点夏普最高」，并附推荐参数的 walk-forward 样本外结论。
- **让 Agent 自主优化**：把标的、策略、当前参数、候选 top3 与样本外结论交给量化 worker，在右侧 Agent 抽屉里流式输出下一步实验设计与证伪条件；不阻塞面板。
- **状态**：空 → 成本口径 + 运行提示；加载 → 按钮禁用、保留上次结果；错误 → 重试；无复权 → 黄条；无逐笔成交 → 图例说明降级。
- **硬约束**：副标题固定「只读研究：回测结论不等于未来收益」。算法说明必须写清信号时点（收盘后计算、次日开盘成交）、T+1、涨跌停不可成交、四项成本与统计口径；Markdown 报告里的交易明细表渲染为真实表格，不降级为等宽文本。

### 4.7 知识库 knowledge

- **目的**：检索口径与方法论，回答"这个数怎么算的"。
- **布局**：左检索框 + 结果列表（标题 / 命中片段 / 分数），右阅读区（Markdown 渲染）。
- **主操作**：搜索、打开全文、复制引用（带文件路径与段落）。
- **状态**：
  - 空：`知识库为空。放入 content/kb/*.md 后重启即可导入。`
  - 加载：结果列表骨架 3 条。
  - 错误：`检索失败：索引未就绪。` + 重试按钮。
  - 过期：不适用（静态内容），但显示 `索引更新于 <时间>`。

### 4.8 模型设置 modelsettings

- **目的**：用官方预设最快配好一个模型，密钥只写不读。
- **布局**：左列配置卡（provider/模型/baseUrl/上下文/鉴权状态/默认）；右列四步向导：provider 卡片 → 模型下拉（显示上下文/输出，自动填）→ API Key（WorkBuddy 时替换为登录态区块）→ 高级折叠 baseUrl。
- **WorkBuddy 区块**：显示登录账号/网关/到期时间；「登录 WorkBuddy」（国内/国际）、「从 dsh/go-stock 导入」、「刷新模型目录」、「退出登录」；登录在系统浏览器完成，前端轮询；token 不出现在任何界面或返回体。
- **OpenCode**：作为 OpenAI Chat Completions 兼容网关出现在 provider 卡片里，填控制台签发的 API Key 即可。
- **主操作**：保存、测试连通、设为默认、删除。
- **Max Tokens**：选中官方模型时直接使用官方最大输出并只读（提示「官方上限 X」）；只有选「自定义模型」时才允许手填。
- **状态**：预设缺失 → 内置兜底并注明；测试中 → 显示耗时；错误 → 保留服务端原文 + 中文建议。
- **安全**：密钥掩码、保存后不回显、页面无「查看密钥」。

### 4.9 设置中心 console

- **目的**：看清装了哪些插件、是否激活、模型能看到哪些工具，以及安全边界。
- **布局**：顶部 5 个统计（已安装/已激活/工具/面板/服务）+ 五个标签（插件/工具/审计/安全策略/数据源）。
- **主操作**：插件启停（重启生效）、工具搜索、审计查看、策略只读、数据源跳转。
- **状态**：受保护插件开关置灰；停用后常驻「重启生效」条；单标签失败不影响其它标签。


### 4.10 市场中心 marketcenter

- **目的**：一屏看清 A 股大盘位置、市场宽度、涨停梯队与龙虎榜资金。
- **布局**：5 张指数卡（上证/深证/科创50/创业板/北证50）+ 8 个宽度指标（上涨/下跌/平盘、涨停/跌停、炸板/炸板率、两市成交额）+ **同花顺热榜（小时榜/日榜）** + 涨停梯队（按首板/2板/3板/4板+分组）+ 龙虎榜表格。
- **主操作**：刷新；点梯队/龙虎榜行可复制代码或进入 K 线（如实现）；单块数据源失败时其余块照常展示。
- **状态**：骨架 → 数据；单块失败 → 黄色 warnings 条 + 该块空态；当日龙虎榜无数据 → 回退最近交易日并明确标注。
- **热榜**：排名/名称/现价/涨跌幅/热度/排名变化/题材与人气标签；小时榜随快照刷新，日榜首次切换时单独拉取；现价缺失显示「—」。
- **口径**：涨停/跌停/炸板、连板梯队、热榜、龙虎榜都来自同花顺；涨跌家数来自新浪全市场快照并发扫描，失败时降级同花顺 `ths-index` 的单市场口径（家数偏少，会标注）；指数来自腾讯，新浪兜底。所有块只读，不含买卖建议。

### 4.11 数据源 fuyao

- **目的**：把同花顺官方 125 个端点里可用的能力全部可视化，并给出「客户端专用 / 上游暂不可用」的明确占位，不让用户把它误当成 Key 配错。
- **布局**：顶部工具条（标的输入 + tickerSearch 联想 + 多选 chip + 「用自选股填充」 + 刷新节律 + `asOf`/端点路径可复制）→ 13 个分域页签 → 分域内二级视图（seg）。分域：行情 / 涨跌停 / 热榜 / 竞价 / 特色数据 / 资金 / 财务 / 指数板块 / 基金 / 期货期权 / 资讯 / 打新 / 工具长尾。
- **视图与方法**：行情=`quote`+`valuation`+`kline`；涨跌停=`limitPool`+`limitStats`；热榜=`hotRank`；竞价=`auction`；特色数据=`special`（异动/异动原因/异动监控/龙虎榜/机构交易/营业部战绩/营业部历史/筹码形态/新增概念/成交额预测）；资金=`capitalFlow`；财务=`financials`（三大报表 + 五类指标）；指数=`index`（目录→成分股→反查→快照/K 线）；基金=`fund`；期货期权=`futures`/`options`；资讯=`news`；打新=`ipo`；工具=`catalog`+`query`+`calendar`+`marketDump`。
- **刷新节律**：行情快照盘中 3s / 盘后 60s；涨跌停 30s；热榜 60s；竞价仅 9:15–9:25 每 5s，其余静态；资金 30s；快讯 10s；估值/财务/基金/资讯其它/打新/目录手动或日更。页面隐藏（`document.hidden`）时暂停，恢复后重排；目录只在首次进入时取一次。
- **状态**：加载骨架；空结果按 §7 语义（合法空/竞价未开始/今日无涨停/非交易日）；2004 → 客户端专用说明 + 替代口径（资金流→资金流面板，分时→腾讯/新浪）；5003 → 上游暂不可用（非权限，可重试）；参数错误 → 可操作文案 + 重试。
- **口径**（每张表/卡脚注）：成交量单位股（同时给手）、金额单位元、涨跌幅百分数原值、`seal_rate` 为 0~1 比例、`heat` 为热度字符串不做金额格式化；红涨绿跌沿用全局 token。
- **工具/长尾**：目录浏览器可搜索端点 ID/路径/标题并按分组过滤，点击行跳「通用查询」；通用查询支持 JSON 参数 + 表格/原始 JSON 切换，是「所有数据都能看到」的兜底入口。

## 5. 交互细节

### 5.1 红涨绿跌

- CSS 变量沿用 `frontend/src/style.css`：`--up: #ff5a5f`（涨）、`--down: #22c08a`（跌）、`--accent: #e9b44c`。
- **不只靠颜色**：涨跌幅前加符号 `+` / `-`，并在表格中加方向箭头 `▲` / `▼`。色盲用户看符号即可。
- 0.00% 用中性色 `--muted`，不加箭头。
- 涨跌停：数值后加小角标 `停`，颜色加深一档，不加闪烁。

### 5.2 数字格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 价格 | 2 位小数，不加货币符号 | `12.43` |
| 涨跌幅 | 带符号 2 位小数 + `%` | `+2.35%` `-1.20%` |
| 成交额 | ≥ 1 亿用"亿"，≥ 1 万用"万"，2 位小数 | `1.23亿` `4520万` `8300` |
| 资金流净额 | 亿元，2 位小数，带符号 | `+18.60亿` |
| 换手率 | 2 位小数 + `%` | `3.42%` |
| 成交量 | 手（契约单位），≥ 1 万手用"万手"，2 位小数 | `45.20万手` |
| 时间 | `HH:mm:ss` | `14:57:03` |
| 日期 | `YYYY-MM-DD` | `2026-11-10` |
| 耗时 | `< 1000ms` 用毫秒，否则秒 1 位 | `820ms` `1.4s` |

不使用千分位逗号（中文语境下"1.23亿"更易读）。金额不显示"￥"，避免与账户余额混淆。

### 5.3 快捷键

| 快捷键 | 动作 | 备注 |
|---|---|---|
| `⌘K` / `Ctrl+K` | 聚焦搜索 | 全局唯一搜索入口 |
| `⌘1`…`⌘9` | 切换面板 | 顺序与左侧导航一致（当前 11 个面板；第 10 个起用搜索或点击导航） |
| `⌘B` | 折叠导航 | 只留图标，状态持久化 |
| `⌘J` / `Ctrl+J` | 打开/关闭 Agent 输出抽屉 | 任意面板可用 |
| `Esc` | 关闭抽屉 | 不退出应用 |

快捷键在地域上区分 `⌘`（macOS）与 `Ctrl`（其它），显示时按平台自动替换。上表之外没有其它全局快捷键；新增组合键要先改本节再实现，避免文档承诺界面没有的行为。

### 5.4 加载与反馈

- 骨架屏延迟 300ms 出现，避免快速接口造成闪烁。
- 超过 8 秒未返回：显示 `仍在请求，可继续操作其它面板`，不阻塞界面。
- 所有写操作完成后给一次轻提示（底部右侧，3 秒自动消失），不使用模态框。
- 破坏性操作（删除自选、清空会话）需二次确认，确认文案写明影响范围。

### 5.5 排序与筛选

- 表格默认按涨跌幅降序；点击表头切换升/降序，三态循环（降 → 升 → 取消）。
- 筛选条件显示在表头下方一行 tag，可单独移除。
- 不提供"隐藏列"以外的布局自定义（P0 阶段不做拖拽布局）。

## 6. 可访问性

- **对比度**：正文与背景 ≥ 4.5:1，大字（≥ 18px）≥ 3:1。`--muted` 仅用于次要信息，不承载关键数据。
- **键盘可达**：所有交互元素可 Tab 到达，焦点环 2px 且可见（不用 `outline: none`）。
- **语义**：表格用 `<table>` 或 `role="grid"`，表头 `scope`；图表提供文本替代（结论栏即替代文本）。
- **动效**：遵守 `prefers-reduced-motion`，关闭过渡与骨架动画。
- **颜色非唯一通道**：涨跌用符号 + 数值；错误用图标 + 文案；禁用态用透明度 + `aria-disabled`。
- **字号**：正文 13px，表格 13px，标题 15/18/22px 三档；行高 1.6。支持浏览器缩放至 150% 不破版。
- **屏幕阅读器**：流式输出区 `aria-live="polite"`，工具调用卡片 `aria-label` 含工具名与状态。

## 7. 文案规范

### 7.1 语气

- 用"你"，不用"您"。
- 陈述句，不用感叹号，不用"！""~""啦"。
- 动词开头："同步自选""运行盘前计划""导出复盘"。
- 不使用营销词："智能""一键""极速""黑科技"。

### 7.2 术语表（全产品统一）

| 用 | 不用 |
|---|---|
| 涨跌幅 | 涨幅百分比 |
| 主力净额 | 主力资金 |
| 前复权 / 后复权 | 复权 / 除权修正 |
| 观察名单 | 股票池 / 自选池 |
| 复盘 | 总结 / 回顾 |
| 失效条件 | 止损条件 |
| 数据滞后 | 数据过期 / 数据旧 |

### 7.3 错误文案三段式

`发生了什么` + `为什么` + `下一步`。一段不超过 2 行。

示例：

- 好：`同步失败：本机未找到同花顺数据目录。请给终端完全磁盘访问权限后重试，或改用网页登录同步。`
- 差：`操作失败！请重试。`

错误必须保留服务端原文（例如 HTTP 状态与错误码），不翻译、不美化。

### 7.4 空状态与引导

- 空状态一句话说明"这里会有什么" + 一个主操作按钮，不超过 2 个动作。
- 不写"暂无数据"这种无信息量的文案，写清为什么空、怎么才能不空。

### 7.5 合规措辞（硬约束）

- 任何结论旁必须有 `仅用于研究记录` 的定位说明，一处即可，不重复堆叠。
- 禁止出现："建议买入""目标价""必涨""稳赚""胜率高"。
- 绩效数字必须与样本量同时出现：`+12.3%（样本 47 笔）`。
