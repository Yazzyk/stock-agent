# 交互与视觉规范（UX）

版本：v1.0 · 2026-11-10 · 对应前端骨架 `frontend/`（Vue3 + TS）

## 1. 设计原则

1. **数字优先**：能用一个数字说清的事，不写一段话。每块内容的第一行是结论，数字带单位与口径。
2. **状态可见**：任何异步数据必须能回答"这是什么时候的、准不准"。不允许无时间戳的行情。
3. **可回退**：所有写操作（同步、保存、运行）先给可撤销入口，不可撤销的要二次确认并说明后果。
4. **不制造压力**：不弹窗催操作、不红色闪烁、不用感叹号。研究工具不该让人焦虑。
5. **一屏一任务**：每个面板只服务一个 job（见 PRD 第 3 节），不堆功能。

## 2. 信息架构

```
观澜
├─ 顶栏（面板标题 / 搜索 ⌘K / 数据健康指示灯 / 总体状态 / Agent 输出开关 ⌘J）
├─ 左侧导航（插件贡献的面板槽位，按 order 排序，每项带 ⌘序号提示）
│   ├─ 自选 watchlist（行情 10）
│   ├─ 资金流 fundflow（行情 20）
│   ├─ K 线 kline（行情 30）
│   ├─ Watch 哨兵 watch（研究 35）
│   ├─ Agent agentlab（研究 40）
│   ├─ 量化研究 quant（研究 45）
│   ├─ 知识库 knowledge（研究 50）
│   └─ 模型设置 modelsettings（设置 90）
├─ 主工作区（当前面板）
├─ 右侧抽屉（Agent 输出，⌘J 开关）
└─ 状态栏（插件 / 工具 / 面板 / 模型 / 服务数量、演示数据标签、更新时间）
```

导航项来自 `Plugins()[].ui`，不写死。只有已激活插件贡献的面板才会出现在导航里；一个都没有时，主区显示「没有可用面板」并提示查看内核日志中插件激活失败的原因。插件是否激活用 --task=plugins 查。

## 4. 八个面板

本节描述**设计目标**。当前界面已实现到什么程度，以 `docs/USER-GUIDE.md` 第 3 节为准；两者不一致时，验收按 USER-GUIDE 与实际界面判定，本节只作为后续迭代的目标。

### 4.1 自选 watchlist

- **目的**：一屏看完自选股当前状态，并判断哪些需要进入今日计划。
- **布局**：表格为主。列：代码 / 名称 / 现价 / 涨跌幅 / 成交额 / 换手率 / 主力净额 / 更新时间。分组用可折叠分组头。
- **主操作**：同步同花顺（右上）、添加标的（表头 +）、按分组筛选。
- **状态**：
  - 空：`还没有自选股。先同步同花顺自选，或点右上角添加。`（附「同步」按钮）
  - 加载：表格骨架 6 行，不显示"加载中"文字。
  - 错误：`同步失败：本机未找到同花顺数据。` + 下一步（检查完全磁盘访问权限 / 改用网页登录）。
  - 过期：行尾角标 `滞后 3 分钟`，超过 5 分钟整表降透明度到 0.6。

### 4.2 资金流 fundflow

- **目的**：判断资金在往哪个板块走，以及个股是否被板块解释。
- **布局**：上下两段。上段板块排名表（行业/概念切换 tab，列：板块 / 涨跌幅 / 主力净额 / 净额占比 / 排名变化）；下段选中板块的成分股表。
- **主操作**：切换行业/概念、按净额或涨跌幅排序、点击板块联动下段。
- **状态**：
  - 空：`暂无板块资金流数据。检查数据源状态后重试。`
  - 加载：两段各自骨架，上段先出。
  - 错误：`资金流接口返回异常：<原因>。已保留上次数据（<时间>）。`
  - 过期：顶部固定条 `数据截至 14:32（盘中值）`，15:05 前始终显示"盘中值"字样。
- **口径**：面板右上角固定一行 `口径：超大单+大单，单位元`，点击展开说明（链接到知识库）。

### 4.3 K 线 kline

- **目的**：看某只标的的位置、量能、结构，给出失效位。
- **布局**：左图右栏。图区 K 线 + 均线（MA20/MA60）+ 成交量副图；右栏为判读结论（趋势/位置/量能/失效位）与复权切换。
- **主操作**：切周期（日/周/60 分）、切复权（不复权/前复权/后复权）、十字光标读数。
- **状态**：
  - 空：`先在自选里选一只标的。`（未选标的时整图区显示提示，不显示空图表）
  - 加载：图表区显示坐标轴与一条水平线，不做闪烁动画。
  - 错误：`K 线数据不足（< 60 根），无法判断趋势。`（这是业务错误，文案要给出阈值）
  - 过期：图上角标 `最后一根：2026-11-07（非交易日）`。
- **强制规则**：复权开关必须常显，默认前复权；切换到不复权时在图上加一行提示 `不复权价格在除权日不连续`。

### 4.4 Watch 哨兵 watch

- **目的**：把「我一直盯着」变成「条件命中才看」。用户声明盯什么，引擎定时求值，命中后派一次 Agent 任务并留下结论。
- **布局**：上方规则列表（列：开关、名称、触发源摘要、条件、最近触发、触发次数）；下方分三块——规则编辑器（基本信息 / 触发源 / 条件 / 动作 / 冷却与静默窗口）、试运行结果、触发日志。编辑器右侧常驻「指标白名单」速查（22 个，按 quote/flow/sector/kline/news/time 分组）。
- **主操作**：从模板新建、保存、开关（toggle）、试运行（test）、删除、查看日志、从模板新建后关着保存（默认 `enabled=false`）。
- **条件输入**：只允许白名单指标 + 比较运算符 + `and/or/not` + 括号。输入时提供指标名补全；写了非白名单标识或函数调用，即时红字提示并禁止保存（不做「先存后报错」）。
- **试运行区看什么**：命中徽标（`matched`）、每个标的/板块一行（名称、关键指标实测值、是否命中）、将要发给 Agent 的 `prompt` 原文、取数耗时。文案必须写清「只求值，不触发 Agent」。
- **日志区看什么**：时间、规则名、worker、指标快照、Agent 结论摘要、错误原因；空时写「还没有触发记录」，不要写「暂无数据」。
- **状态**：
  - 空：`还没有规则。可以从模板新建，或直接告诉 Agent「半导体板块主力净流入超过 20 亿就提醒我」。`
  - 加载：规则列表骨架 3 行；引擎 `running=false` 时顶部常驻横幅 `Watch 引擎未运行，规则不会求值`。
  - 错误：单条规则文件格式非法时，只在该行标记 `规则文件格式非法：<文件名>（<原因>）`，不影响其它规则；整体读取失败才用整块错误态。
  - 过期：不适用（求值实时）。但「最近触发」超过 24 小时要在行尾灰字标出，提示可能是条件过严或引擎未运行。
- **硬约束（文案与交互都要体现）**：
  - 条件只能读白名单指标，**不提供脚本输入框**，不出现「执行」「运行代码」这类字眼；
  - 触发动作只能选 worker + 填 prompt，不能配命令、不能配文件写入路径；
  - 保存前必须通过校验（名称、至少一个触发源、条件可解析、worker 合法），校验失败逐条给出中文原因。
- **实现状态**：已交付（`frontend/src/panels/watch.vue`，研究组 order 35，浏览器验证通过）。落地形态与本节一致：顶部一句话创建 + 从模板新建 / 新建规则 / 刷新，左侧规则列表带开关，右侧编辑器（触发源增删、条件输入 + 指标 chips 插入、保存 / 试运行 / 删除），底部触发日志。
### 4.5 Agent agentlab

- **目的**：跑盘前/盘中/盘后/量化四类任务，看到步骤与产物。
- **布局**：左侧会话列表，中间对话流（含工具调用卡片），右侧产物文件树（`runs/<date>/`）。
- **主操作**：选择 worker、输入一句话目标、运行/停止、打开产物。
- **状态**：
  - 空：`还没有会话。选一个任务开始：盘前计划 / 盘后复盘 / 量化验证。`
  - 加载：对话流顶部显示 `正在调用 market.quote`（工具名可见，这是可审计性的第一层）。
  - 错误：工具失败显示为**结果卡片而非报错弹窗**（模型需要读到错误文本继续推理）。
  - 过期：产物文件带生成时间；文件被外部修改时提示 `文件已在外部修改，点击重新载入`。

### 4.6 量化研究 quant

- **目的**：验证一个规则在过去是否成立，并且让读者知道这份结论有多可信。
- **布局**：上方参数区（策略、代码、周期、初始资金、折数）+「运行回测」「walk-forward」两个按钮；结果区左侧指标卡与成本卡（佣金/印花税/过户费/滑点/成本合计/区间），右侧净值曲线，下接「回测报告 / walk-forward」两个标签。
- **主操作**：选策略、填参数、运行回测；做过拟合检验时点 walk-forward。
- **状态**：
  - 空：`还没有回测结果。填好代码与参数后点「运行回测」`，并附成本口径四项。
  - 加载：按钮变成「回测中…」并禁用，结果区保留上一次内容。
  - 错误：`回测失败：<原因>` + 「重试」。
  - 降级：无真实复权序列时顶部出现黄色警告条，说明本次按不复权计算。
- **硬约束**：副标题固定写「只读研究：回测结论不等于未来收益」；报告必须含五关自检与成本四行。

### 4.7 知识库 knowledge

- **目的**：检索口径与方法论，回答"这个数怎么算的"。
- **布局**：左检索框 + 结果列表（标题 / 命中片段 / 分数），右阅读区（Markdown 渲染）。
- **主操作**：搜索、打开全文、复制引用（带文件路径与段落）。
- **状态**：
  - 空：`知识库为空。放入 content/kb/*.md 后重启即可导入。`
  - 加载：结果列表骨架 3 条。
  - 错误：`检索失败：索引未就绪。` + 重试按钮。
  - 过期：不适用（静态内容），但显示 `索引更新于 <时间>`。

### 4.8 模型设置 modelsettings

- **目的**：配置 provider 与密钥，确认模型可用，查看安全策略。
- **布局**：上段 provider 列表（名称/模型/是否有 key/是否默认），中段表单（BaseURL、模型、密钥），下段只读策略区（网络白名单、允许路径、限额）。
- **主操作**：保存、测试连通性、设为默认、查看审计。
- **状态**：
  - 空：`还没有配置模型。填写 BaseURL 与密钥后点测试。`
  - 加载：测试按钮转为 `测试中…` 并禁用，显示已耗时。
  - 错误：`连通失败：HTTP 401 Authentication Fails。检查密钥是否有效。`（保留服务端原文，不翻译）
  - 过期：不适用。
- **安全**：密钥输入框默认掩码，只显示后 4 位；保存后不回显明文；页面不提供"查看密钥"。

## 5. 交互细节

### 5.1 红涨绿跌

- CSS 变量沿用 `frontend/src/style.css`：`--up: #ef4b4b`（涨）、`--down: #2fbf71`（跌）。
- **不只靠颜色**：涨跌幅前加符号 `+` / `-`，并在表格中加方向箭头 `▲` / `▼`。色盲用户看符号即可。
- 0.00% 用中性色 `--muted`，不加箭头。
- 涨跌停：数值后加小角标 `停`，颜色加深一档，不加闪烁。

### 5.2 数字格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 价格 | 2 位小数，不加货币符号 | `12.43` |
| 涨跌幅 | 带符号 2 位小数 + `%` | `+2.35%` `-1.20%` |
| 成交额 | ≥ 1 亿用"亿"，≥ 1 万用"万"，2 位小数 | `1.23亿` `4520万` `8300` |
| 资金流净额 | 亿元，2 位小数，带符号 | `+18.60亿` |
| 换手率 | 2 位小数 + `%` | `3.42%` |
| 成交量 | 手（契约单位），≥ 1 万手用"万手"，2 位小数 | `45.20万手` |
| 时间 | `HH:mm:ss` | `14:57:03` |
| 日期 | `YYYY-MM-DD` | `2026-11-10` |
| 耗时 | `< 1000ms` 用毫秒，否则秒 1 位 | `820ms` `1.4s` |

不使用千分位逗号（中文语境下"1.23亿"更易读）。金额不显示"￥"，避免与账户余额混淆。

### 5.3 快捷键

| 快捷键 | 动作 | 备注 |
|---|---|---|
| `⌘K` / `Ctrl+K` | 聚焦搜索 | 全局唯一搜索入口 |
| `⌘1`…`⌘8` | 切换面板 | 顺序与左侧导航一致（当前 8 个面板） |
| `⌘J` / `Ctrl+J` | 打开/关闭 Agent 输出抽屉 | 任意面板可用 |
| `Esc` | 关闭抽屉 | 不退出应用 |

快捷键在地域上区分 `⌘`（macOS）与 `Ctrl`（其它），显示时按平台自动替换。上表之外没有其它全局快捷键；新增组合键要先改本节再实现，避免文档承诺界面没有的行为。

### 5.4 加载与反馈

- 骨架屏延迟 300ms 出现，避免快速接口造成闪烁。
- 超过 8 秒未返回：显示 `仍在请求，可继续操作其它面板`，不阻塞界面。
- 所有写操作完成后给一次轻提示（底部右侧，3 秒自动消失），不使用模态框。
- 破坏性操作（删除自选、清空会话）需二次确认，确认文案写明影响范围。

### 5.5 排序与筛选

- 表格默认按涨跌幅降序；点击表头切换升/降序，三态循环（降 → 升 → 取消）。
- 筛选条件显示在表头下方一行 tag，可单独移除。
- 不提供"隐藏列"以外的布局自定义（P0 阶段不做拖拽布局）。

## 6. 可访问性

- **对比度**：正文与背景 ≥ 4.5:1，大字（≥ 18px）≥ 3:1。`--muted` 仅用于次要信息，不承载关键数据。
- **键盘可达**：所有交互元素可 Tab 到达，焦点环 2px 且可见（不用 `outline: none`）。
- **语义**：表格用 `<table>` 或 `role="grid"`，表头 `scope`；图表提供文本替代（结论栏即替代文本）。
- **动效**：遵守 `prefers-reduced-motion`，关闭过渡与骨架动画。
- **颜色非唯一通道**：涨跌用符号 + 数值；错误用图标 + 文案；禁用态用透明度 + `aria-disabled`。
- **字号**：正文 13px，表格 13px，标题 15/18/22px 三档；行高 1.6。支持浏览器缩放至 150% 不破版。
- **屏幕阅读器**：流式输出区 `aria-live="polite"`，工具调用卡片 `aria-label` 含工具名与状态。

## 7. 文案规范

### 7.1 语气

- 用"你"，不用"您"。
- 陈述句，不用感叹号，不用"！""~""啦"。
- 动词开头："同步自选""运行盘前计划""导出复盘"。
- 不使用营销词："智能""一键""极速""黑科技"。

### 7.2 术语表（全产品统一）

| 用 | 不用 |
|---|---|
| 涨跌幅 | 涨幅百分比 |
| 主力净额 | 主力资金 |
| 前复权 / 后复权 | 复权 / 除权修正 |
| 观察名单 | 股票池 / 自选池 |
| 复盘 | 总结 / 回顾 |
| 失效条件 | 止损条件 |
| 数据滞后 | 数据过期 / 数据旧 |

### 7.3 错误文案三段式

`发生了什么` + `为什么` + `下一步`。一段不超过 2 行。

示例：

- 好：`同步失败：本机未找到同花顺数据目录。请给终端完全磁盘访问权限后重试，或改用网页登录同步。`
- 差：`操作失败！请重试。`

错误必须保留服务端原文（例如 HTTP 状态与错误码），不翻译、不美化。

### 7.4 空状态与引导

- 空状态一句话说明"这里会有什么" + 一个主操作按钮，不超过 2 个动作。
- 不写"暂无数据"这种无信息量的文案，写清为什么空、怎么才能不空。

### 7.5 合规措辞（硬约束）

- 任何结论旁必须有 `仅用于研究记录` 的定位说明，一处即可，不重复堆叠。
- 禁止出现："建议买入""目标价""必涨""稳赚""胜率高"。
- 绩效数字必须与样本量同时出现：`+12.3%（样本 47 笔）`。

## 8. 待办与已知缺口

- 明暗主题：当前仅有暗色（`color-scheme: dark`），浅色主题 P2。
- 移动端：不做，产品定位桌面研究台。
- 多窗口/分屏：P2。
- 图表库选型：由 frontend 决定，本规范只约束视觉与交互。
