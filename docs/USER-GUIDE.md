# 使用手册

面向使用者：怎么把观澜用起来，出问题时怎么自己查出来。技术实现看 `docs/ARCHITECTURE.md`，接口形状看 `docs/API.md`，口径见 `docs/DOMAIN.md`。

## 0. 它是什么，不是什么

**是**：本地运行的研究台。抓行情、看资金流、读 K 线、让 Agent 按固定流程写盘前计划与盘后复盘、跑量化回测并给出可信度自检。

**不是**：

- 不是荐股工具。它不输出买入/卖出/目标价。
- 不下单。没有任何交易接口，也不接券商通道。
- 不预测点位。所有结论是研究记录，不是建议。
- 不联网同步你的数据。全部落在本机 `~/.guanlan`。

## 1. 启动

### 1.1 桌面端

```sh
wails build -clean     # 构建，产物在 build/bin/
```

开发时用热重载：

```sh
wails dev
```

首次启动会自动创建数据目录 `~/.guanlan`（权限 0700）。

### 1.2 无界面模式（排障首选）

同一套内核，不开窗口，跑一个任务就退出：

```sh
go run . --headless --task=selftest
```

可用参数：

| 参数 | 取值 | 说明 |
|---|---|---|
| `--headless` | 布尔 | 无界面模式 |
| `--task` | 见下表 | 要执行的任务，默认 `selftest` |
| `--data-dir` | 路径 | 数据目录，默认 `~/.guanlan`；也可用环境变量 `GUANLAN_DATA_DIR` |
| `--log-level` | debug/info/warn/error | 日志级别，默认 info；也可用 `GUANLAN_LOG_LEVEL` |
| `--log-file` | 路径 | 同时写日志文件 |

任务清单：

| task | 作用 |
|---|---|
| `selftest` | 检查插件是否全部激活、工具/面板/服务数量、模型与数据源状态 |
| `plugins` | 列出插件及其工具/面板/方法数量 |
| `tools` | 列出工具索引（名称、风险等级、摘要） |
| `quote` | 取快照，例：`--task=quote -- 600000` |
| `bars` | 取 K 线，例：`--task=bars -- 600000 day 60` |
| `watchlist` | 取自选列表 |
| `watches` | 列出全部 Watch 规则、触发日志与可用指标 |
| `watch-test` | 试运行一条规则，例：`--task=watch-test -- <规则ID>`（只求值，不触发 Agent） |
| `premarket` / `postmarket` | 跑盘前 / 盘后 worker |
| `monitor` | 跑盘中 worker |
| `quant` | 跑量化 worker |
| `chat` | 跑通用对话 worker |
| 任意工具名 | 兜底：把 task 当工具名直接调用，参数为空对象，便于排障 |

### 1.3 数据目录

`~/.guanlan` 下主要有：sqlite 数据库、`runs/`（每日产物）、`skills/`（用户自定义技能）、以及你用 `--log-file` 指定的日志。

所有写盘都必须在这个目录内，越界会被安全策略拒绝。

## 2. 五分钟上手

| 步骤 | 在哪做 | 做什么 | 完成标志 |
|---|---|---|---|
| 1 | 设置 → 模型设置 | 新增 Provider，填 BaseURL 与密钥，点测试 | 列表里出现该模型，标记为默认 |
| 2 | 行情 → 自选 | 点「同步同花顺」，或搜索后添加标的 | 表格里出现你的分组与标的 |
| 3 | 行情 → 资金流 | 切到「板块」，点「刷新排名」 | 看到当日板块主力净额排名 |
| 4 | 研究 → Agent 实验室 | 选 `premarket`，填一句话目标，点「运行」 | 「报告」标签出现当日计划正文，`~/.guanlan/runs/<日期>/plan.md` 已生成 |
| 5 | 收盘后 | 选 `postmarket` 运行 | 出现 `review.md`，对账表能和早上的计划逐条对上 |

## 3. 十个面板

左侧导航按分组排列，顺序即快捷键顺序：**研究**（Agent 工作台 · 总控 → Watch 哨兵 → 量化研究 → 知识库）、**行情**（自选 → 市场中心 → 资金流 → K 线）、**设置**（模型设置）、**系统**（设置中心）。Agent 工作台固定第一，是默认落地页。只显示已激活插件贡献的面板；少了某个面板时，按本节末尾的方法排查。

### 3.1 自选

- **界面**：顶部是数据源状态条（本机同花顺 / 网页登录 / 手工文件三枚状态点 + 「待授权」/「可用」）、同步按钮与列设置；下面是分组标签和行情表格。
- **首次使用**：打开面板会自动执行一次 `check` 诊断；没有自选且某一路来源可用时自动 `sync`，不需要先点按钮。
- **同步向导**（条件出现）：四步 `local / web-login / web-capture / manual`，每步一个主按钮：
  - 「打开系统设置」→ macOS 完全磁盘访问深链；授权后每 2 秒重新检测，最多 60 次，就绪即自动同步。
  - 「打开登录页」→ 浏览器打开同花顺个人中心；登录后点「自动读取」（Safari 可直读，Chrome 因钥匙串加密需「粘贴登录态」）。
  - 「复制数据目录」→ 手工导入 `watchlist.json` 的兜底路径。
  - 手动「粘贴登录态」：先验证再落盘（`~/.guanlan/ths_cookie.txt`，0600），校验不过不写文件。
- **表格列**：代码、名称、分组、现价、涨跌幅、成交额、换手、主力净额、主力占比、走势（当日分时小图）、操作；「列」按钮可关掉成交额/换手/5日主力等。操作列固定在右侧，不随横向滚动跑掉。
- **行内动作**：「K线」把标的送到 K 线面板并立即加载；「分时」或点击走势小图打开当日分时大图（价格/均价/昨收/成交量，悬停看读数）；「资金」从右侧滑出 420px 资金抽屉（五项指标 + 多日双轴图 + 区间 + 摘要 + 打开 K 线）。
- **刷新**：行情每 5 秒自动刷新，可暂停；数据来自缓存时名称旁挂「缓存」角标。
- **失败时**：向导会指出缺哪一步；表格与手动同步照常可用（单只资金失败该列显示 —，不影响列表）。

### 3.2 资金流

- **板块/概念资金流线**：默认画「主力净流入 TOP8 + 净流出 TOP8」的区间累计主力净额曲线（流入红、流出绿），最多同时对比 20 个板块。图线右端标注板块名称，图例显示名称、当日涨跌幅与累计值；顶部摘要给流入/流出 TOP 的名称与涨跌幅。可切 10/20/60 日；点图例隐藏/显示单线；悬停看该日各线读数；点下方榜单行可把该板块加入或移出图线，点「重置图表」恢复默认 TOP8+8。
- **摘要行**：覆盖板块数、区间净流入合计、区间净流出合计、交易日数。
- **资金排名**：板块 / 概念切换，分成「主力净流入 TOP」和「主力净流出 TOP」两榜并排展示；列为排名、名称、涨跌幅、主力净额、主力占比；点任意行加入/移出上方图线（不再切到个股视角）。红入绿出。
- **降级**：板块/概念资金榜与板块多日资金流都只有新浪一条链路（`ssl_bkzj_bk` / `ssl_bkzj_zjlrqs`），没有第二家兜底。新浪不可达时两个榜保留上次数据并显示黄条与原因，涨跌幅与主力占比整列隐藏（不显示误导性的 0），图线尽量沿用上次数据。
- **只读**：图线与榜单都是对已发生数据的描述，**不含买卖建议**；本面板不再显示个股资金卡。
- **口径**：个股主力净额 = 超大单 + 大单（新浪 `r0_net + r1_net`）；板块/概念榜是新浪 `netamount` 的**板块全部资金净额**，不是主力口径，两者不要混在一张表里比较。单位元，展示换算成亿元。盘中取到的是滚动值，收盘后刷新才是当日最终值。
- **能做什么**：`stock` / `rank` / `sectors` / `history`（个股多日）/ `sectorHistory`（板块/概念多日）/ `sectorBatch`（板块批量）/ `batch`（个股批量，自选列使用）。

### 3.3 K 线

- **顶部**：可搜索标的（自选优先 + 全市场）、周期段控件（日/周/月/60 分）、指标开关（MA/BOLL/量/MACD）、「最新」「研判」「最大化」。
- **自选快捷条**：图表上方一排 chips（最多 20 只），点一下即切标的。
- **读数条**：日期、开高低收、涨跌幅、振幅、量额、MA5/10/20/60；切到 MACD 时显示 DIF/DEA/MACD。
- **主图**：蜡烛 + 影线 + MA（可关）+ BOLL（可关）+ 十字光标 + 右轴价格标签；副图成交量，打开 MACD 时量收窄、MACD 独立副图。
- **操作**：滚轮以鼠标位置为锚点缩放、拖拽平移、双击复位、←/→ 平移、+/- 缩放、Home 回到最新；底部显示「视窗 N 根 / 共 M 根 · 复权口径」。
- **右侧研判**：可折叠（窄屏自动收起）；先选「短线 / 长线」——短线看近 60 根的 MA5/10/20、RSI、MACD 与 60 日结构位，长线看近 250 根的 MA20/60/120 与长周期结构；每个尺度给 bias（偏多/偏空/中性）、趋势、指标、形态与支撑阻力。底部注明「只描述结构，不构成买卖建议」。
- **联动**：自选行「K线」、全局搜索、量化面板都会写入 `state.focus`，本面板立即切换并高亮；加载中显示 skeleton，不闪空白。
- **复权**：默认前复权；数据源没有真实复权序列时显式降级为不复权并在底部标注，不静默。

### 3.4 Watch 哨兵

- **它解决什么**：把「我盯着呢」变成「条件命中自动派一次研究任务」。你声明盯什么，引擎每 30 秒取数求值，命中后触发一次 Agent 任务，并把结论与指标写进触发日志。
- **安全边界（先看这条）**：规则是**声明式 JSON**，条件只能对白名单指标做数值比较，**不能调用函数、不能访问网络、不能执行代码**。它是安全的表达式 DSL，不是脚本引擎；触发动作也只是「给 Agent 派一次带模板的任务」，不写任意文件、不接交易。
- **可用指标（22 个）**：

下表是可直接写进 `condition` 的完整标识符，共 22 个：

| 前缀 | 指标 |
|---|---|
| `quote.` | `quote.price` 现价（元）、`quote.changePct` 涨跌幅（%）、`quote.volumeRatio` 量比、`quote.turnover` 换手率（%）、`quote.amount` 成交额（元） |
| `flow.` | `flow.mainNet` 主力净额（元）、`flow.mainNetYi` 主力净额（亿元）、`flow.mainNetPct` 主力净额 ÷ 成交额（%） |
| `sector.` | `sector.changePct` 板块涨跌幅（%）、`sector.mainNet` 板块主力净额（元）、`sector.mainNetYi` 板块主力净额（亿元） |
| `kline.` | `kline.rsi` RSI(14)、`kline.ma20dev` 距 MA20（%）、`kline.volumeRatio` 5 日量比、`kline.macd` MACD 柱、`kline.aboveMA20` 站上 MA20（1/0）、`kline.atrPct` ATR 占收盘（%） |
| `news.` | `news.hits` 命中公告/新闻条数、`news.negative` 负面词命中（1/0） |
| `time.` | `time.trading` 是否交易时段（1/0）、`time.hour` 小时、`time.minute` 分钟 |

- **规则字段**：`name`、`description`、`enabled`、`sources`（1–6 个）、`condition`、`action`、`cooldownSeconds`、`quietWindows`（如 `11:30-13:00`）。运行时会附带 `lastTriggeredAt`、`triggerCount`、`lastError`。
- **触发源五种**：`quote`（个股，需 `codes`）、`sector`（板块/概念名，`sector` + `kind`）、`kline`（个股 + `period`，默认 day）、`news`（`keyword` + `kind`=notice/roll）、`schedule`（`times`，如 09:20）。
- **条件语法**（契约见 `docs/API.md` §5.6）：数值比较 `> >= < <= == !=`（实现也接受 `=` 与 `<>`），逻辑 `and`/`or`/`not`（也接受 `&&`/`||`/`!`），支持括号与 `true`/`false`。例：`sector.mainNetYi > 20 and quote.changePct > 3`。
- **动作**：`action.worker` 取 `chat`/`intraday`/`premarket`/`postmarket`/`quant`；`action.prompt` 是模板，可插入 `{quote.changePct}`、`{sector.mainNetYi}`、`{keyword}`、`{summary}` 等占位。
- **试运行看什么**（`test`，不触发 Agent）：`matched` 是否命中、`scenarios[]` 每个标的/板块的 `metrics` 实测值与是否命中、`summary` 一句话结论、`prompt` 会发给 Agent 的原文、`elapsedMs` 取数耗时。先试运行再启用，是避免误报的标准动作。
- **触发日志**（`logs` / `--task=watches`）：时间、规则名、worker、是否触发、指标快照、Agent 结论、错误原因、耗时；最多保留 200 条。
- **限流与时段**：单规则按 `cooldownSeconds` 冷却；全局每小时最多 6 次触发；非交易时段不求值（`TradingOnly`）。
- **文件即插件**：规则落在 `~/.guanlan/watches/<id>.json`，改文件后 30 秒内热加载生效，不用重启。
- **用一句话让 Agent 写规则**：直接说需求，Agent 调 `watchdog.create` 生成规则（可用 `watchdog.list` 查、`watchdog.toggle` 开关、`watchdog.test` 试运行、`watchdog.logs` 看日志）。例：「半导体板块主力净流入超过 20 亿就提醒我看看持续性」。
- **面板已交付**（研究组，序 35）：顶部是「一句话创建」输入框（让 Agent 把需求写成规则）与「从模板新建 / 新建规则 / 刷新」；左侧规则列表带开关与最近触发；右侧编辑器可增删触发源、写条件（下方指标 chips 点一下即插入对应指标名）、保存 / 试运行 / 删除；底部是触发日志与「刷新日志」。没有规则时提示「还没有 Watch 规则」，并说明规则命中只会派一次 Agent 任务。命令行等价入口：`--task=watches`、`--task=watch-test -- <id>`。

### 3.5 Agent 实验室

- **三张值班卡**（盘前 / 盘中 / 复盘）：显示开关、下次运行倒计时、上次结果（成功/失败/未配置模型/运行中）、时间或频率、「编辑提示词」「立即运行」。**盘前/复盘的时间用卡片上的时、分下拉直接改**（改完立即保存并重算下次运行）；**盘中用「时段」按钮改交易时段**（上午/下午各一段），频率仍是 15/30/60 分钟。**不需要用户先发消息**：开关打开后调度器按提示词自动触发。
- **编辑提示词**：模态里改行为描述（20–8000 字），可「恢复默认」；三级披露协议由代码统一追加，用户改不掉。
- **默认和总控对话**：输入框默认发给「总控（router）」。总控会先理解目标：简单问题直接答；需要盘前/盘中/复盘/量化时用 `agent.spawn` 派给对应 worker；没有合适 worker 时先创建一个再派。最终由总控汇总成一份结论。
- **Worker 列表**：内置（总控/盘前/盘中/复盘/量化/问答）与自定义两组。点任意 worker 会切到右侧 Worker 详情（模型、提示词摘要、最近 5 个会话），并自动打开最近一次会话的日志与报告；运行中点击只提示先停止，不打断。
- **只读 Worker**：只有「总控（主控）」有对话框；其它 Worker 是**完全只读视图**——不渲染输入框，只显示「由总控分派运行」的说明。任务请交给总控，由总控分派；盘前/盘中/复盘仍可由值班卡或调度自动触发。
- **新建 Worker**：在 Worker 区点「新建」，填 id/标题/描述/提示词/模型；创建后即可被总控或 `agent.spawn` 使用，最多 20 个。
- **模型选择**：顶部下拉可为 Agent 选择模型（只列已配置 Key 的项）；模板里也能为单个 worker 保存默认模型。优先级：本次显式选择 > worker 模板 > 系统默认模型。
- **运行日志**：左侧和右侧都会随选中 worker 切换；流式输出合并成一个持续生长的段落，重复的盯盘心跳合并显示。
- **空回复诊断**：正文为空时报告页给诊断卡而不是一句「模型没有返回内容」——后端返回 `emptyReason` + `diagnostics`（内容过滤 / 仅推理 / `finish_reason=length` / 预算 / 空 chunk / 错误），页面给出「把输出上限调到 8192 后重试 / 换一个模型 / 看运行日志」三条动作。
- **上下文**：「上下文」标签页给出 KPI 行（已用 / 窗口 / 占比 / 步数）、system / tools / messages 组成环形图、逐轮趋势、事件流与口径说明（参考 dsh-context 的上下文洞察页）；标题栏另有一枚可点开的小环。没选中会话时也会回读快照——后端 `agentlab.context` 在 `sessionId` 为空时回退到最近一次会话。未拿到窗口时只显示「~已用」。
- **编队**：全宽页面（左侧 worker 列表收起），谱系树（父→子连线、状态点、token、耗时、步数）+ worker 花名册（按真实 worker 分组，根会话区分「主会话（总控）」与「根会话（盘前计划）」）+ 节点详情（可打开子会话日志，报告块可滚动、按钮常驻可见）；顶部「1 个主会话 / N 个子智能体」。主会话可通过 `agent.spawn` 派生子智能体，子会话不能再派生。
- **插话**：运行中输入框自动切「插话」，内容在下一次模型调用前并入上下文；队列上限 5 条。
- **步数/预算耗尽**：仍会生成一份收口报告（结论/依据/不确定性/风险提示），尾部说明卡在工具调用步数还是 token 预算。**Token 默认不设预算上限**（`MaxTokensPerRun=0`），停机只由单次运行的工具调用上限与模型单次输出上限决定；只有在策略里显式写了 >0 的预算时才会因预算停机。
- **任意面板查看**：`⌘J` 打开运行抽屉，抽屉里同样有上下文环。

### 3.6 量化研究

- **参数**：标的用 `StockPicker`（自选优先 + 全市场搜索）、周期、策略、快慢线、初始资金、折数；右上「运行回测」「walk-forward」。
- **结果**：8 个指标卡（总收益/年化/最大回撤/夏普/胜率/交易笔数/换手/期末权益）+ 成本明细；下方上下两段图：
  1. **标的 K 线**：区间价格 + 均线 + 买卖标记（B/S，读回测顶层 `trades`；没有逐笔成交时图例会明确说明）；
  2. **净值曲线**：初始资金基准虚线、回撤阴影可开关、hover 读数。
- **成本口径**：佣金万三（最低 5 元）、印花税卖出万五、过户费双边 0.001%、滑点单边千分之一。
- **算法说明**：参数区下方可展开，列出全局成交口径（收盘后计算、次日开盘成交、T+1、涨跌停不可成交、四项成本、复权降级、年化/夏普/胜率算法）与当前策略的公式、规则和参数范围。
- **walk-forward**：输出样本内/样本外收益与过拟合缺口及判定。
- **参数优化**：「参数优化」标签在默认网格上评估候选，按邻域稳健性挑推荐参数，再跑 walk-forward；报告会明确警告「不要用单次回测最优参数直接上线」。
- **让 Agent 自主优化**：带着当前参数与优化 top3 打开 Agent 抽屉，量化 worker 会给出下一步实验设计与证伪条件。
- **降级**：没有真实复权序列时顶部黄条提示；回测只用于检验规则，不是选股依据。

### 3.7 知识库

- **界面**：顶部「检索 / 文档 / 技能」三个标签，右侧阅读器，右上角「导入」。
- **能做什么**：检索（`search`）、文档列表（`list`）、打开全文（`open`）、导入（`import`）、技能目录（`skills`）、查看技能（`skill`）。
- **内置内容**：10 篇口径文档 + 10 个技能（盘前计划、盘后复盘、盯盘、K 线读图、资金流解读、量化诚实性、实盘冠军短线战法、超短线七位一体、游资席位与龙虎榜、中文报告润色）。后 4 个从 dsh / openclaw 导入，来源与适配见 [docs/SKILLS-IMPORT.md](SKILLS-IMPORT.md)。
- **导入**：粘贴 Markdown 正文，可填标题与标签，点「确认导入」。
- **技能是什么**：一段可执行流程。模型按它做事，而不是每次重新解释方法论。

### 3.8 模型设置

- **列表**：每个配置一张卡（provider、模型、baseUrl、上下文窗口、鉴权状态、默认标记）；非默认配置卡上可直接点「设为默认」切换全局默认（不需要重填 Key），状态栏的「模型」会同步更新。密钥只写不读。WorkBuddy 配置显示「本机登录态可用 / 未登录」，不显示 token。
- **新增/编辑分四步**：① 选 provider 卡片（DeepSeek / OpenAI / 通义 / 方舟 / Ollama / OpenAI 兼容 / OpenCode 兼容网关 / WorkBuddy）；② 选模型下拉（选项显示上下文与最大输出，自动填 baseUrl / maxTokens / contextWindow）；③ 填 API Key（WorkBuddy 改为登录态区块：登录 / 从 dsh、go-stock 导入 / 退出）；④ 高级折叠才允许改 baseUrl。
- **Max Tokens**：选中官方模型后自动使用官方最大输出并**只读**（例如 DeepSeek 384K），不需要也不允许手改；只有选「自定义模型」时才允许手填（默认 8192，上限 1M）。旧配置里存过较小值的，按新口径显示官方上限，保存后按官方上限写入。
- **能做什么**：`list` / `save` / `setDefault` / `test` / `remove` / `presets`（预设无网络）；WorkBuddy 另有 `workbuddyStatus` / `workbuddyModels` / `workbuddyLogin` / `workbuddyLoginPoll` / `workbuddyImport` / `workbuddyLogout`。
- **WorkBuddy**：没有个人 API Key，走本机登录态。点「登录 WorkBuddy」在浏览器完成授权，凭证保存在本应用数据目录（0600）；已登录过 dsh 或 go-stock 的可直接「导入」。退出只清本应用凭证。
- **OpenCode**：BaseURL 默认 `https://opencode.ai/inference/openai/v1`，在 OpenCode 控制台签发 API Key 后填入；模型 ID 从 `qwen3.8-max`、`deepseek-v4.1-flash`、`kimi-k2.5`、`glm-5.3` 等 Chat Completions 模型里选。
- **密钥**：输入框掩码，保存后不回显；任何返回都不含明文 key。

### 3.9 设置中心

- **五个标签**：插件 / 工具 / 审计 / 安全策略 / 数据源。
- **插件**：卡片显示状态（已激活/已停用/失败+原因）、版本、ID、依赖、标签、工具·方法·面板数、启用开关；停用会写盘并提示「重启应用后生效」；设置中心自身受保护，开关置灰。
- **工具**：可搜索，显示风险等级与来源插件——这是排查「模型能看到什么」的地方。
- **审计**：最近 100 条（时间/插件/动作/耗时/结果），失败高亮，敏感字段已脱敏。
- **安全策略**：网络白名单、路径根（已脱敏为 ~）、限流、工具调用上限、是否允许 exec（只读）。
- **数据源**：健康状态 + 「去同步」跳到自选。上游只有三家：
  - 同花顺 `10jqka.com.cn`：自选股、涨停/跌停/炸板池与连板梯队、龙虎榜、人气热榜、K 线兜底；
  - 腾讯 `gtimg.cn`：指数与个股快照、当日分时、K 线（前复权 `qfqday` / 后复权 `hfqday`）；
  - 新浪 `sinajs.cn` / `sina.com.cn`：个股快照兜底、涨跌家数、个股资金流、板块/概念资金榜与多日资金流。
  - 东方财富（eastmoney）已从数据层完全移除，登录态与 Cookie 相关功能一并下线——设置中心不再有「东财登录态」卡片，也没有「打开东财 / 自动读取浏览器 Cookie / 手动填写 Cookie」按钮。


十个面板里若少了某个，用 `go run . --headless --task=plugins` 看该插件是否激活；`--task=selftest` 末尾显示「结果: OK」表示全部激活（当前 10/10）。若导航里有该项、点开却显示「面板组件缺失」，那是前端组件未交付，不是插件没激活。

### 3.10 市场中心

- **指数卡**：上证指数、深证成指、科创50、创业板指、北证50；显示点位、涨跌幅、成交额，红涨绿跌。
- **市场宽度**：上涨/下跌/平盘家数、涨停/跌停家数、炸板数与炸板率、两市成交额。
- **同花顺热榜**：小时榜 / 日榜切换，列出排名、名称、现价、涨跌幅、热度、排名变化、题材与人气标签；小时榜带「上榜原因」，日榜侧重持续人气。
- **涨停梯队**：按首板 / 2 板 / 3 板 / 4 板及以上分组，列出代码、名称、涨幅、首次/最后封板时间、涨停原因与金额；最高板高亮。
- **龙虎榜**：当日上榜个股、上榜原因、净买入/买入/卖出，按净买入绝对值降序；当日无数据自动回退最近交易日并标注。
- **口径**：涨停/跌停/炸板、连板梯队、热榜、龙虎榜都来自同花顺（龙虎榜是 GBK HTML 表格解析，不是结构化 JSON）；涨跌家数来自新浪全市场快照并发扫描，失败时降级同花顺 `ths-index` 的**单市场**口径（家数会明显偏少，会标注）；指数来自腾讯，新浪兜底。单块失败只降级该块并显示黄条。只读研究，不含买卖建议。

## 4. 四个标准操作流

产物统一落在 `~/.guanlan/runs/<YYYY-MM-DD>/`。

### 4.1 盘前（08:30–09:15）

1. **确认今天是交易日**：跑 `go run . --headless --task=bars -- 000001 day 1`，最后一条日期不是今天就是休市（`000001` 是上证指数）。
2. **读昨日复盘**：知识库或文件里打开 `runs/<上一交易日>/review.md`，只取三类：应验情况、遗留观察、昨日"不做的事"。
3. **看自选**：`stale` 的条目不参与判断；涨幅 > 9% 和跌幅 > 7% 的分开看。
4. **定板块强弱**：资金流面板切「板块」，看主力净额前 10 / 后 5。板块涨且净流入才是同向。
5. **跑盘前**：Agent 实验室选 `premarket`，输入一句话（例如"今天重点看半导体，仓位上限 8%"），点运行。
6. **检查产物**：`plan.md` 里每个标的必须有 触发条件 / 失效条件 / 止损位 / 计划仓位，缺一项就重跑。

### 4.2 盯盘（09:15–15:00）

1. **只在几个时刻看**：09:25、10:00、10:30、13:30、14:45。其余时间不刷。
2. **集合竞价**：9:20 之后不能撤单，9:25–9:30 交易所不接受申报，别在这两段动手。
3. **记录触发**：条件成立就留一条（时间/价格/成交额/主力净额/判断），用 `intraday` worker 或笔记。
4. **异常优先**：跌幅 3% 未修复、触及止损位、板块资金方向反转、停牌、数据中断超过 3 分钟，先记异常。
5. **情绪拦截**：盘中只允许 记录 / 按计划执行 / 标记失效；想追的念头写进记录，收盘归因。

### 4.3 复盘（15:00–17:00）

1. **跑盘后**：Agent 实验室选 `postmarket`，点运行。它会读当天 `plan.md` 与实际行情。
2. **对账**：`review.md` 的对账表应逐条给出 触发且执行 / 触发未执行 / 未触发 / 条件失效。
3. **归因只留一个主因**：数据、执行、逻辑、情绪。多因等于没因。
4. **次日假设 2–3 条**：今天无法判定、明天可以判定。
5. **确认记忆写入**：事实型（口径、接口行为）与教训型（可复用的失误模式）各写一条。

### 4.4 量化（任意时段）

1. **准备**：确认回测区间 ≥ 2 年、复权口径固定、股票池含退市标的。
2. **跑**：两种路径——量化研究面板填参数点「运行回测」（看指标卡与净值曲线），或 Agent 实验室选 `quant` worker 让它自己组织规则（产出报告正文）。做过拟合判断时点面板上的「walk-forward」。
3. **读报告**：`report.md` 第一节必须是五关自检——未来函数、样本内外、walk-forward、幸存者偏差、参数敏感性。
4. **核对成本**：报告必须列出佣金、印花税、过户费、滑点四行，口径与 `docs/DOMAIN.md` §4.3 一致（往返约 0.262%）。
5. **不通过的结论不看绩效**：自检书没通过，后面的年化数字没有意义。

### 4.5 自定义盯盘（Watch 哨兵）

适用：你有几条固定的关注点，但不可能一直盯盘。把它们写成规则，命中时让 Agent 去看一眼并把结论留在日志里。

**标准动作（无论盯什么，顺序都一样）**：

1. **写规则**：说清楚「盯谁 + 什么条件 + 命中后让谁做什么」。可以直接对 Agent 说，让它调 `watchdog.create`；也可以自己写 JSON 放进 `~/.guanlan/watches/`。
2. **先试运行**：`go run . --headless --task=watch-test -- <规则ID>`，看 `scenarios[].metrics` 里指标的真实取值、`matched` 是否命中。不命中先改阈值，别急着启用。
3. **启用**：`watchdog.toggle`（或面板开关）。默认 `enabled=false`，模板生成的新规则一律先关着。
4. **看日志**：`--task=watches` 看 `logs`，每条含时间、指标快照、Agent 结论、错误原因。
5. **控噪**：命中太频繁就加 `cooldownSeconds`（模板里 600/900/1800 秒）或补 `quietWindows`（如 `09:25-09:35` 竞价噪声段）。全局每小时最多 6 次。

**三个可直接抄的例子**：

| 想盯什么 | 规则要点 |
|---|---|
| 半导体板块资金 | `sources: [{type:"sector", sector:"半导体", kind:"sector"}]`；`condition: "sector.mainNetYi > 20"`；`action.worker: "intraday"`，prompt 让它判断资金持续性 |
| 某股放量突破 | `sources: [{type:"kline", codes:["600000"], period:"day"}]`；`condition: "kline.volumeRatio > 2 and kline.aboveMA20 > 0"`；prompt 让它区分真突破与诱多 |
| 并购重组公告 | `sources: [{type:"news", keyword:"并购重组", kind:"notice"}]`；`condition: "news.hits > 0"`；`action.worker: "chat"`，prompt 让它列受益方向与待验证数据 |

**边界**：条件只能读第 3.4 节列出的 22 个指标。想盯的东西如果不在白名单里（例如某个自定义指标），先提需求，不要试图在条件里写函数或运算表达式——解析器会直接拒绝（这也是它安全的原因）。

**别做的事**：把规则当交易信号自动执行（本产品没有交易通道）；用 `schedule` 源在非交易时段刷 Agent（引擎本来就只在交易时段求值）；一次建 10 条以上规则（每小时触发上限会让你错过真正重要的那条）。

## 5. 模型配置

按接入方式分为三类：

| provider | 用途 | 需要的字段 |
|---|---|---|
| `deepseek` | DeepSeek 官方接口 | `model`（例 `deepseek-flash`）、`apiKey`；BaseURL 默认 `https://api.deepseek.com` |
| `openai` / `qwen` / `ark` / `ollama` / `openai-compat` | 官方或任意 OpenAI 兼容接口 | `baseUrl`、`model`、`apiKey`（Ollama 可留空） |
| `opencode` | OpenCode 兼容网关（Chat Completions） | `apiKey`；BaseURL 默认 `https://opencode.ai/inference/openai/v1` |
| `workbuddy` | WorkBuddy 本机登录态（国内 / 国际） | 无需 `apiKey`；先登录或从 dsh / go-stock 导入，模型从账号目录里选 |

表单字段：`provider`、`name`（显示名，可选）、`baseUrl`、`model`、`apiKey`、`maxTokens`（默认 8192）、`setDefault`（保存时设为默认）。

测试结果怎么读：

| 结果 | 含义 | 下一步 |
|---|---|---|
| `ok=true` + 延迟几十到几百毫秒 | 通了 | 设为默认 |
| `ok=false` + HTTP 401 | 密钥无效或已撤销 | 重新获取密钥 |
| `ok=false` + HTTP 429 | 限流或余额不足 | 稍后重试，或换通道 |
| `ok=false` + 超时 | 网络不通或 BaseURL 写错 | 检查 BaseURL 与代理 |
| `ok=false` + 模型不存在 | `model` 名字不对 | 按服务商文档改模型名 |
| `ok=false` + 未找到 WorkBuddy 登录凭证 | 本机没登录过 | 点「登录 WorkBuddy」或在 dsh / go-stock 登录后点「导入」 |
| `ok=false` + WorkBuddy 400（11101/11128） | 网关协议校验失败 | 通常是请求形态问题；保留错误码反馈，不要反复重试 |
| `ok=false` + 401（OpenCode） | API Key 无效或未开通模型 | 到 OpenCode 控制台检查 Key 与模型权限 |

密钥不进日志：审计与错误信息里出现的 `sk-`、`Bearer`、`token=` 都会被脱敏成 `***`。

## 6. 数据来源与口径

| 用途 | 来源 |
|---|---|
| 个股/指数 K 线 | 腾讯 `fqkline`（前复权 `qfqday` / 后复权 `hfqday`）；不复权走腾讯原始 → 新浪日线 → 同花顺兜底 |

| 个股资金流 | 新浪 MoneyFlow（当日 `ssi_ssfx_flzjtj`：r0~r3 成交额分档，净额 = in − out，主力净额 = `r0_net + r1_net`；多日 `ssl_qsfx_zjlrqs` 上游只给 `r0_net`，多日的「主力」是超大单净额，比当日窄） |
| 板块/概念资金榜 | 新浪 `MoneyFlow.ssl_bkzj_bk`；板块代码是新浪 category（如 `new_dzxx`） |
| 板块/概念多日资金流 | 新浪 `MoneyFlow.ssl_bkzj_zjlrqs` |
| 涨跌家数 | 新浪全市场快照并发扫描；失败降级同花顺 `ths-index` 单市场口径 |
| 涨停/跌停/炸板、连板梯队、龙虎榜、热榜 | 同花顺 |
| 指数快照 | 腾讯 `qt.gtimg.cn`，新浪兜底 |
| 快照主源 | 同花顺 |
| 快照兜底 | 腾讯、新浪 |
| 自选股 | 同花顺（本机客户端 → 网页登录 → 手工导入，三级降级） |

网络只走白名单：`10jqka.com.cn`、`gtimg.cn`、`sinajs.cn`、`sina.com.cn`、`sina.cn`、`hexun.com`、`deepseek.com`、`openai.com`。名单外的域名会被拒绝，不会静默失败；已下线数据源的主机（如 `eastmoney.com`）在读取旧策略时会被自动剔除，避免旧配置把接口悄悄接回来。

单位（与 `docs/API.md` 一致）：

- 金额：元
- 成交量：手（1 手 = 100 股）
- 涨跌幅：百分数，`2.34` 表示 +2.34%
- 日期：`YYYY-MM-DD`；时间：RFC3339

`stale=true` 表示这条数据是缓存的旧值，不要用它做判断。

## 7. 自检与排障

先跑总检：

```sh
go run . --headless --task=selftest
```

它输出插件激活数、工具/面板数量、服务列表、数据源健康、模型清单。最后一行是 `结果: OK` 或 `结果: FAIL（插件未全部激活）`。

症状对照：

| 症状 | 先跑 | 判读 |
|---|---|---|
| 面板空白 / 左侧没有导航 | `--task=selftest` | `插件: 0 个` 说明插件没接线，不是界面问题 |
| 某按钮提示"工具不存在" | `--task=tools` | 该工具没注册，对应插件未激活 |
| 提示"插件不存在" | `--task=plugins` | 插件未注册（构建漏了 import） |
| 没有行情 | `--task=quote -- 600000` | 报网络错误查白名单与网络；返回 `stale=true` 查数据源 |
| K 线是空的 | `--task=bars -- 600000 day 60` | 返回条数 < 60 说明数据不足；报错看错误原文 |
| 自选是空的 | `--task=watchlist` | 返回 `success=false` 时按 `needFullDiskAccess`/`needWebLogin` 处理 |
| 模型不能回答 | `--task=selftest` 看模型行 | `key=false` 是没配密钥；`hasKey=true` 仍失败看测试结果 |
| 盘前没产物 | `--task=premarket` | 报告里 `error` 字段写明原因；看 `runs/<日期>/` 是否生成 |
| 界面报"Wails 运行时未注入" | — | 用浏览器直开了页面，必须用 `wails dev` 或桌面端启动 |

日志：加 `--log-file=/tmp/guanlan.log --log-level=debug` 再跑一次，日志会同时写文件。提交问题时附这段日志（已脱敏）。

## 9. 已知限制

- **复权**：前复权与后复权都由腾讯 `fqkline` 提供（键 `qfqday` / `hfqday`），除权日前后的历史价按对应口径调整；不复权走腾讯原始序列 → 新浪日线 → 同花顺兜底。腾讯取不到对应序列时会明确报"不支持 / 请改用不复权或前复权"，不会拿别的序列冒充。K 线底部与量化面板按后端返回的 `adjust`/`warning` 显示口径，看到降级提示不是故障。
- **自动值班**：按周一至周五近似判断交易日，法定节假日可能误触发；可在值班卡里临时关掉，或调后 `at` 时间。
- **登录态**：`~/.guanlan/ths_cookie.txt` 为明文 0600（先验证再落盘，接口与日志不回显）；换 macOS 钥匙串是后续加固项。
- **板块多日资金流**：个股与板块/概念都走新浪（个股 `ssl_qsfx_zjlrqs`，板块 `ssl_bkzj_zjlrqs`），点榜单行即可加入图线；某些板块上游没有 `r0_net` 时用 `netamount` 兜底，返回项带 `source` 标注实际口径。
- **周期**：只支持日/周/月/60 分。`min15`/`min5`/`min1` 不支持，请求会明确报错。
- **情绪指标**：涨停家数、炸板率、连板高度只有知识库口径（`theme-sentiment-cycle.md`），没有对应工具与面板。
- **Watch 限制**：条件只能读 22 个白名单指标，不支持自定义指标与函数；非交易时段不求值。
- **Watch 条件能力**：只能对 22 个白名单指标做数值比较，不支持自定义指标与函数；非交易时段不求值。
- 没有实时 Level-2、没有逐笔委托，分钟级是上限。
- 无云端同步：换机器要自己搬 `~/.guanlan`。
- 只有一个主题（暗色）。
