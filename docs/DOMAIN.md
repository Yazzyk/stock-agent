# A 股业务口径与约束

本文是**口径真源**：交易时段、涨跌停、资金流分档、回测成本，代码与本文冲突时，以本文为准并同步改代码。
版本：v1.0（2026-11-10）。规则类内容标注生效日期，未标日期的视为长期有效。

## 0. 适用范围

本产品做**只读研究**：抓行情、算指标、跑回测、写计划与复盘。不做下单、不做资金划转、不接券商通道。

因此本文的规则不是为了交易执行，而是为了**让研究结论与真实市场一致**：回测里能成交的，实盘也得能成交；口径算错的涨跌幅，不能让复盘结论偏。

## 1. 市场与交易规则

### 1.1 交易日历

- 交易日 = 沪深交易所开市日。周末与法定节假日休市，A 股没有半日交易。
- 年度休市安排由交易所每年 12 月前后公布，**不得硬编码到代码或配置里**。
- 判定今天是否交易日：取 `market.bars("000001", limit=1)`，最后一条的日期等于今天才是交易日。
- 一年约 242–245 个交易日。跨年计算年化时必须用实际交易日数，不要用 365。
- 历史异常：2016-01-04、2016-01-07 因熔断机制提前收市；熔断机制自 2016-01-08 起暂停至今。

### 1.2 交易时段（北京时间）

| 时段 | 名称 | 规则 |
|---|---|---|
| 09:15–09:20 | 开盘集合竞价 | 可申报、可撤单 |
| 09:20–09:25 | 开盘集合竞价 | 可申报、**不可撤单** |
| 09:25 | 开盘价产生 | 集中撮合，成交量最大原则 |
| 09:25–09:30 | 静默期 | 交易所不接受申报 |
| 09:30–11:30 | 连续竞价 | 可申报、可撤单 |
| 11:30–13:00 | 午间休市 | — |
| 13:00–14:57 | 连续竞价 | 可申报、可撤单 |
| 14:57–15:00 | 收盘集合竞价 | 不可撤单，收盘价由此产生 |
| 15:05–15:30 | 科创板盘后固定价格交易 | 按收盘价成交，2019-07-22 起 |

收盘集合竞价：深交所 2006 年起实行，上交所 2018-08-20 起实行。

### 1.3 T+1 与结算

- **股票 T+1**：当日买入，次一交易日才能卖出。回测撮合必须实现这条约束，否则同一标的会被当日反复交易，收益虚高。
- **T+0 品种**：可转债、跨境 ETF、债券 ETF、货币 ETF。股票型 ETF 仍是 T+1。混用时按品种分别处理。
- **资金**：卖出所得当日可继续买入，T+1 可提现。
- 分红送股到账通常在除权除息日之后 1–3 个交易日，研究时按除权日调整价格，不模拟到账时点。

### 1.4 涨跌停

| 板块 | 代码前缀 | 限制 | 生效 |
|---|---|---|---|
| 沪市主板 | 600/601/603/605 | ±10% | 长期 |
| 深市主板 | 000/001/002/003 | ±10% | 长期 |
| 创业板 | 300/301 | ±20% | 2020-08-24 起 |
| 科创板 | 688/689 | ±20% | 2019-07-22 起 |
| 北交所 | 8xxxxx / 4xxxxx | ±30% | 2021-11-15 起 |
| 主板 ST / *ST | — | ±5% | 长期 |
| 创业板 / 科创板 ST | — | ±20% | 注册制下与普通股一致 |

计算规则：

- 涨跌停价 = 前收盘价 × (1 ± 限制比例)，**四舍五入到 0.01 元**。
- 前收盘价在除权除息日等于除权（息）参考价，不是昨日实际收盘价。
- 新股：主板上市首日涨幅上限 44%、跌幅下限 36%，次日起 ±10%；科创板、创业板上市后前 5 个交易日不设涨跌幅限制。
- 无涨跌幅限制期间设盘中临时停牌：较开盘价涨跌达 30%、60% 各停牌 10 分钟。

对回测的硬约束：

- 涨停价上无法买入，跌停价上无法卖出，撮合时标记"无法成交"并顺延到下一交易日开盘，**不能假设以涨停价成交**。
- 一字板（开盘即涨停且全天未打开）视为无法成交。

### 1.5 停牌

| 情形 | 规则 | 生效 |
|---|---|---|
| 重大资产重组 | 停牌不超过 10 个交易日 | 2018-11 起 |
| 异常波动核查 | 交易所可要求停牌，通常 1 个交易日 | 长期 |
| 退市整理期 | 15 个交易日，期间风险警示 | 2020-12-31 退市新规起 |
| 未披露定期报告 | 可被强制停牌 | 长期 |

对数据的含义：

- 停牌日没有 K 线。不要用前值填充成交量，那会制造不存在的交易。
- 停牌期间持仓按停牌前价格估值，回测里视为不可交易。
- 复牌首日集中成交，资金流与量比失真，单独标记。

### 1.6 除权除息与复权

除权（息）参考价：

```
参考价 = (前收盘价 - 每股现金红利 + 配股价 × 配股比例) / (1 + 送股比例 + 转增比例 + 配股比例)
```

三种口径，用途不同，**不能混用**：

| 口径 | `market.bars` 参数 | 用途 | 风险 |
|---|---|---|---|
| 不复权 | `adj=""` | 看当日真实成交价、算手续费 | 除权日跳空，涨跌幅失真 |
| 前复权 | `adj="qfq"` | 看形态、看均线 | 历史价格随每次除权变化，回测不可复现 |
| 后复权 | `adj="hfq"` | 算长期收益、跑回测 | 价格数值与实盘差异大，不适合看盘口 |

**回测必须锁口径**：用后复权，或在回测开始时把复权因子快照落盘，之后不再重算。否则今天跑出来的年化，明天就变了。

除权日的涨跌幅按除权参考价计算，不是昨日收盘价。这是"为什么我的策略在除权日莫名亏损"的最常见原因。

## 2. 资金流口径

资金流是按**单笔成交额分档**、按**主动买卖方向**统计的推断值，不是账户数据。

### 2.1 分档标准（新浪口径）

个股当日资金流走新浪 `MoneyFlow.ssi_ssfx_flzjtj`，`r0`~`r3` 四档各给买入额与卖出额：

| 档位 | 上游字段 | 净额算法 |
|---|---|---|
| 超大单 | `r0_in` / `r0_out` | `r0_net = r0_in − r0_out` |
| 大单 | `r1_in` / `r1_out` | `r1_net = r1_in − r1_out` |
| 中单 | `r2_in` / `r2_out` | `r2_net = r2_in − r2_out` |
| 小单 | `r3_in` / `r3_out` | `r3_net = r3_in − r3_out` |
| 主力 | — | `r0_net + r1_net`（与旧东财「超大单 + 大单」同名口径等价） |

- `r0`~`r3` 的 `*_in` / `*_out` 是**成交额**，净额必须自己做差；直接取 `rN` 当净额是错的。
- 分档门槛由新浪定义，不与旧东财阈值逐档对齐；跨数据商比较金额前先统一口径。
- 单位：**元**。前端展示换算为亿元，保留 2 位小数。
- 自洽校验：四档净额之和应等于上游 `netamount`（实测相等）。校验不过的数据直接丢弃并记录警告。
- **多日口径更窄**：多日接口 `ssl_qsfx_zjlrqs` 只给 `r0_net`、`netamount`、`turnover`、`changeratio`，没有 r1~r3 的拆分，所以多日序列的 `mainNet` 取超大单净额、`mainPct` 用 `r0_ratio`。多日的「主力」与当日的「主力（超大 + 大）」不是同一个数，不要画在同一条曲线上比较。
- **板块层再不同**：板块/概念资金榜的 `netamount` 是**板块全部资金净额**，不分主力/散户，不能与个股主力净额直接比较。

### 2.2 有效性阈值

```
主力净流入占比 = mainNet / amount
```

| 占比 | 判定 |
|---|---|
| < 1% | 噪声，忽略 |
| 1%–5% | 弱信号，需连续 3 日 |
| > 5% | 强信号，需板块层验证 |

绝对金额不可跨股票比较：2 亿净流入在成交额 80 亿的标的上是噪声，在 8 亿的标的上是主导。

### 2.3 失真情形（必须在结论里标注）

| 情形 | 失真原因 | 处理 |
|---|---|---|
| 大宗交易 | 不计入逐笔主动成交 | 单独看折溢价 |
| ETF 申赎、指数调样 | 被动买卖计为大单 | 查当日公告 |
| 涨跌停封板 | 封单不计入主动成交 | 用封单量判断 |
| 新股前 5 日 | 无涨跌幅限制 | 不参与板块均值 |
| 复牌首日 | 挂单集中 | 只记录不判断 |
| 集合竞价成交 | 方向归属不规范 | 剔除 09:25 那一笔的归属判断 |

### 2.4 板块与概念映射

- 行业板块：按申万 / 新浪分类，一只股票归属唯一行业。
- 概念板块：数据商人工维护，一只股票可属多个概念，**个股调入调出有 1–3 个交易日滞后**。
- 板块资金流由新浪直接按板块口径给出（`netamount` 为板块全部资金净额，不做市值加权），**不要当成成分股主力净额的加总**。
- 用板块解释个股时：取该股成交额最大的板块，不得挑最符合结论的那个；结论里必须写"板块成分更新至 <日期>"。

## 3. 四个工作流

统一产物路径：`~/.guanlan/runs/<YYYY-MM-DD>/`（必须通过 `Guard.CheckPath`）。

### 3.1 盘前 premarket（08:30–09:15）

| 项 | 内容 |
|---|---|
| 输入 | 上一交易日收盘数据、昨日 `review.md`、自选股、板块资金流、隔夜公告 |
| 步骤 | 判定交易日 → 读昨日复盘 → 拉自选快照 → 板块强弱排序 → 个股结构判定 → 写计划 → 三问自检 → 落盘 |
| 输出 | `plan.md`：数据截止时间、环境判断、观察名单（≤5 只）、待验证假设（2–3 条）、不做的事 |
| 失败模式 | 数据截止写成"现在"（不可复现）、标的超过 5 个（执行不了）、缺失效条件 |

每个标的最小字段集：`触发条件 / 失效条件 / 止损位 / 计划仓位 / 依据`。四缺一即视为计划未完成。

### 3.2 盘中 intraday（09:15–15:00）

| 项 | 内容 |
|---|---|
| 输入 | 当日 `plan.md`、实时快照、当日资金流 |
| 步骤 | 四个观察窗口（09:25 / 10:00 / 10:30 / 13:30 / 14:45）→ 触发式记录 → 异常优先 → 情绪拦截 → 收盘前收尾 |
| 输出 | `ticklog.md`：事件表（时间/代码/价格/涨跌幅/成交额/主力净额/触发条件/判断）、异常、情绪记录、收尾 |
| 失败模式 | 每分钟刷屏、盘中改阈值、临场新增标的、下移止损 |

### 3.3 盘后 postmarket（15:00–17:00）

| 项 | 内容 |
|---|---|
| 输入 | 当日 `plan.md`、收盘行情、`ticklog.md` |
| 步骤 | 取收盘数据 → 逐条对账 → 单一主因归因 → 算当日结果 → 生成次日假设 → 回写记忆 → 落盘 |
| 输出 | `review.md`：对账表、归因（数据/执行/逻辑/情绪）、当日结果、次日假设、记忆写入 |
| 失败模式 | 只记录不判定、归因写三个以上、记忆写成日记 |

"未触发"必须量化距离：最高价距触发价 1% 以内记"差一点"，> 3% 记"条件脱离实际"。

### 3.4 量化 quant（任意时段）

| 项 | 内容 |
|---|---|
| 输入 | 后复权日线、历史成分股（含退市）、成本参数 |
| 步骤 | 锁复权快照 → 写规则 → 回测（含成本）→ 样本内外 70/30 → walk-forward ≥4 段 → 参数邻域扫描 → 幸存者偏差检查 → 写报告 |
| 输出 | `report.md`：自检表（五关结论前置）、绩效、成本明细、已知缺口 |
| 失败模式 | 同日成交、零成本、样本外反复使用、用当前成分回溯 |

## 4. 量化诚实性

### 4.1 未来函数（六类，出现任一即结论作废）

1. 同日成交：T 日收盘信号在 T 日成交。
2. 指标窗口越界：计算 T 日指标读到 T+1 数据。
3. 极值触发：用当日最高/最低价判定触发。
4. 财务数据回填：用最新一期财报回溯历史（应按公告日）。
5. 不可成交假设：涨停买入、跌停卖出。
6. 榜单错位：T 日收盘后公布的龙虎榜、资金流在 T 日使用。

### 4.2 样本外与 walk-forward

- 切分：前 70% 选参，后 30% 只验证一次。
- 判定：样本外年化 / 样本内年化 < 0.5 → 过拟合。后段交易笔数 < 60 时该比值不稳定，需标注。
- walk-forward：≥4 段，每段训练 ≥2 年，逐段独立选参，拼接净值扣成本；段间参数跳变 > 50% 视为不稳定。

### 4.3 成本模型（唯一口径，与 `docs/ROADMAP.md` 一致）

| 项目 | 参数 | 生效说明 |
|---|---|---|
| 佣金 | 双边 0.03%，单笔最低 5 元 | 长期 |
| 印花税 | 卖出 0.05% | 2023-08-28 起由 0.1% 减半 |
| 过户费 | 双边 0.001% | 2022-04-29 起沪深统一 |
| 滑点 | 单边 0.1%（10bp） | 低流动性标的可上调至 0.2% |

单次完整往返：

```
cost = 0.03% × 2 + 0.05% + 0.001% × 2 + 0.1% × 2 = 0.262%
```

年换手成本估算：`年成本 ≈ 0.262% × 年换手次数`。年换手 24 次约 6.3%，60 次约 15.7%。

成本参数必须写成常量并在报告里列出；同一批对比实验中途不得改口径。

### 4.4 幸存者偏差

三种修正方式，至少做到第一种：

1. 用历史成分股（指数调样记录），不用今天的成分回溯；
2. 显式纳入已退市标的的价格序列；
3. 更名、借壳按交易代码跟踪，不按名称匹配。

小市值策略受影响最大：退市股集中在该区间，剔除会系统性抬高收益。

### 4.5 绩效指标定义

| 指标 | 定义 | 注意 |
|---|---|---|
| 总收益 | 期末净值 / 期初净值 - 1 | 单利，不复利年化 |
| 年化 | (1 + 总收益)^(245 / 交易日数) - 1 | 用 245 而非 365 |
| 最大回撤 | max(1 - 净值 / 历史峰值) | 算净值峰值，不用价格峰值 |
| 夏普 | (年化收益 - 无风险利率) / 年化波动 | 无风险利率取 2%，需写明 |
| 胜率 | 盈利笔数 / 总笔数 | 与盈亏比同时看才有效 |
| 盈亏比 | 平均盈利 / 平均亏损 | 胜率 40% + 盈亏比 2 也能盈利 |

## 5. 风控清单

以下是**研究纪律参数**，用于约束计划与记录，不构成投资建议。默认值可在设置里改，改后必须在报告中写明。

| 项目 | 默认值 | 触发动作 |
|---|---|---|
| 单票仓位上限 | 20% | 计划中标注超限并拒绝落盘 |
| 单板块仓位上限 | 35% | 提示集中度风险 |
| 总仓位上限 | 80% | 保留现金应对回撤 |
| 单笔风险预算 | 账户 1% | 由止损位反推仓位 |
| 日亏损阈值 | -3% | 停止开新仓，只记录 |
| 连续亏损 | 3 笔 | 仓位减半，复盘归因后才恢复 |
| 止损位来源 | K 线结构位 | 禁止用整数或固定百分比 |
| 止损位上移 | 不允许下移 | 变更需单独写理由与时间 |
| 情绪指标降仓 | 涨停家数 > 80 或炸板率 > 30% | 新开仓减少一半 |

情绪指标口径见 `content/kb/theme-sentiment-cycle.md`：涨停家数、炸板率、连板高度、昨涨停今日表现，四项同向才有判断力。
