# 资金流指标口径

资金流不是账户数据，是按成交额分档后对主动买卖方向的统计推断。口径不清，数字就会自相矛盾。

## 分档标准（新浪口径）

个股当日资金流走新浪 `MoneyFlow.ssi_ssfx_flzjtj`，`r0`~`r3` 四档各给买入额与卖出额：

| 档位 | 上游字段 | 净额 |
|---|---|---|
| 超大单 | `r0_in` / `r0_out` | `r0_net = r0_in − r0_out` |
| 大单 | `r1_in` / `r1_out` | `r1_net = r1_in − r1_out` |
| 中单 | `r2_in` / `r2_out` | `r2_net = r2_in − r2_out` |
| 小单 | `r3_in` / `r3_out` | `r3_net = r3_in − r3_out` |

**主力 = 超大单 + 大单**，即 `r0_net + r1_net`（与旧东财同名口径等价），单位元。

- `r0`~`r3` 的 `*_in` / `*_out` 是**成交额**，净额必须自己做差（`in − out`），不能直接取 `rN` 当净额。
- 分档门槛由新浪定义，不与其它数据商逐档对齐；跨数据商比较金额前先统一口径。
- 自洽校验：四档净额之和应等于上游 `netamount`（实测相等）。
- **多日序列更窄**：`ssl_qsfx_zjlrqs` 只给 `r0_net`、`netamount`、`turnover`、`changeratio`，所以多日的「主力」是超大单净额，与当日的「超大 + 大」不是同一个数，不要画在同一条曲线上比较。

## 三个必知的口径事实

1. 分档看单笔成交额，与账户规模无关。大资金拆单会被计入中单，主力净额因此系统性低估机构行为。
2. 主动买卖按逐笔成交方向判定（成交价接近卖一价为主动买）。集合竞价成交的归属不规范。
3. 主力净流入为正只说明大单主动买入多于主动卖出，不构成价格预测。

## 有效性检验：先看比例，再看金额

净流入占成交额比例：

```
ratio = mainNet / amount
```

经验阈值：ratio < 1% 视为噪声；1%–5% 为弱信号；> 5% 且连续 3 日同向，才值得进入结论。绝对值（例如"净流入 2 亿"）在不同成交额的股票之间不可比。

## 哪些情形会让数字失真

| 情形 | 失真原因 | 处理 |
|---|---|---|
| 大宗交易 | 不计入逐笔主动成交 | 单独看折溢价 |
| ETF 申赎、指数调样 | 被动买卖被计入大单 | 查当日公告 |
| 涨跌停封板 | 封单不计入主动成交 | 用封单量与排队资金 |
| 新股前 5 日 | 无涨跌幅限制，波动极端 | 不进板块均值 |
| 复牌首日 | 挂单集中，方向由堆积决定 | 只记录不判断 |

## 板块与概念

行业板块按申万 / 新浪分类，概念板块由数据商人工维护，个股调入调出有 1–3 个交易日滞后，且一只股票可属于多个概念。用板块解释个股时，取该股成交额最大的板块，不要挑最符合结论的那个。板块资金流由新浪按板块直接给出（`netamount` 为板块**全部资金净额**，不分主力/散户，也不做市值加权），不要当成成分股主力净额的加总，它也无法反映板块内部分化。

口径写不清的资金流结论，不可复现，也不可比较。
