# K 线形态手册

K 线只记录四个价格与成交量。形态的价值在于**位置 + 量能 + 实体影线比例**三者的组合，单根 K 线的名字没有意义。

## 读一根 K 线的三件事

1. **实体比例**：|收盘 - 开盘| / (最高 - 最低)。> 0.7 为实体主导，< 0.3 为影线主导。
2. **影线方向与长度**：上影长说明上方抛压，下影长说明下方承接。
3. **量能**：当日成交额 / 前 5 日均额（额比）。< 0.8 缩量，> 1.5 放量。

## 六种可用的组合

| 组合 | 条件 | 含义 | 需次日确认 |
|---|---|---|---|
| 长上影 + 放量 | 上影 ≥ 实体 2 倍，额比 > 1.5 | 高位抛压重 | 是 |
| 长下影 + 放量 | 下影 ≥ 实体 2 倍，额比 > 1.5 | 低位有承接 | 是 |
| 十字星 + 缩量 | 实体 < 全幅 10%，额比 < 0.8 | 分歧收敛，等方向 | 是 |
| 阳包阴 | 当日阳线实体完全覆盖前日阴线实体 | 最小级别的反转证据 | 否 |
| 阴包阳 | 当日阴线实体完全覆盖前日阳线实体 | 上涨结构破坏 | 否 |
| 跳空缺口 | 今日最低 > 昨日最高（向上） | 趋势强，三日不回补视为有效 | 是 |

**缩量两连阴**在上涨过程中更常见于中继，而非见顶；判断依据是价格是否守住关键均线，不是阴线根数。

## 位置决定形态的解释力

同一根长下影，在不同位置含义相反：

- 距 60 日低点 < 10%：可能是止跌信号。
- 距 60 日高点 < 5%：更可能是拉高出货留下的痕迹。

先算位置，再看形态，顺序不能反。位置三指标：距 60 日最高、距 60 日最低、距 MA20。

## 均线排列

- 多头排列：收盘 > MA20 > MA60，且 MA20 斜率向上。
- 空头排列：收盘 < MA20 < MA60。
- 缠绕：MA20 与 MA60 交叉前后，方向不明，此时形态信号成功率显著下降。

均线参数固定（20/60），不要为了好看改成 18/58。

## 失效位怎么取

失效位必须是结构位，四条取法按优先级：

1. 最近一根放量阳线（上涨结构）或放量阴线（下跌结构）的开盘价；
2. 最近一个有效低点/高点（前后各 2 根 K 线未跌破/未突破）；
3. 缺口边缘；
4. 均线（MA20 或 MA60），仅在前三条都不可得时使用。

不要用整数关口，也不要用"跌 5%"。整数是全场共识，被扫概率最高。

## 常见误读

- 用未收盘的当根 K 线做判断：14:00 的长上影到收盘可能变成十字星。
- 不复权看历史：除权日的跳空会被读成暴跌。
- 把连续小阳当强势：缩量小阳是无人接盘，不是买盘强。
- 形态与量能背离时相信形态：量是形态成立的前提。

形态只能给出"当前结构是什么"，不能给出"接下来会怎样"。
