# 复盘模板

复盘的目标是**让明天的判断比今天更可检验**，不是记录今天的感受。模板固定下来，才能跨日比较。

## 一页模板

```markdown
复盘记录 YYYY-MM-DD

## 1. 计划与实际
| 标的 | 触发条件 | 是否触发 | 是否执行 | 偏差 |
|---|---|---|---|---|

## 2. 归因（只写一个主因）
- 数据 / 执行 / 逻辑 / 情绪：具体事件与时间点

## 3. 结果
- 收益率、交易笔数、最大回撤、胜率（无成交写 0 笔）

## 4. 次日假设（2–3 条）
- 今天无法判定、明天可以判定的条件句

## 5. 记忆写入
- 事实：口径、接口、阈值
- 教训：可复用的失误模式
```

## 每条怎么填

**触发条件**必须抄自当日 plan.md 原文，不能改写。改了就无法判断计划本身是否合理。

**是否触发**要量化距离：最高价距触发价 1% 以内记"差一点"，3% 以上记"条件脱离实际"。

**归因只写一个主因**。多因等于没因。四类的判定标准：

| 类型 | 判定标准 |
|---|---|
| 数据 | 用了错口径、缺失值、陈旧数据 |
| 执行 | 条件成立但没做、或做晚了超过 5 分钟 |
| 逻辑 | 假设的因果关系不成立（板块流入但个股跌） |
| 情绪 | 临场新增标的、下移止损、加大仓位 |

**次日假设**必须可判定。反例"明天可能反弹"；正例"若板块主力净流入转负，观察名单缩到 1 只"。

**记忆只写两类**：可复用的口径事实、可复用的失误模式。当日涨跌数字可再生，不写。

## 周度复盘（每周五）

把 5 天的假设汇总，回答三个问题：

1. 本周写了多少条假设，应验多少条？（应验率 < 40% 说明假设质量有问题）
2. 归因分布：数据/执行/逻辑/情绪各占多少？
3. 有没有同一种失误重复出现 2 次以上？有则写成规则。

## 不该出现在复盘里的东西

- 当日盈亏的绝对值（没有仓位与成本口径，数字无意义）；
- 对指数点位的预测；
- 转述的群消息与传闻；
- "今天操作很烂"这类自我评价——换成具体事件与时间。

复盘的价值在于跨日可比较。填不满模板时，错误信息比空白更有价值：写"未记录"，不要编。
