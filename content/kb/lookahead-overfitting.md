# 未来函数与过拟合

回测里有两类错误会让结论系统性偏乐观：用了当时不知道的信息（未来函数），以及把噪声当规律（过拟合）。两者都不报错，只报高收益。

## 六类未来函数

| 类型 | 具体表现 | 检查方法 |
|---|---|---|
| 同日成交 | 用 T 日收盘信号在 T 日成交 | 成交价必须来自 T+1 |
| 指标窗口越界 | 计算 T 日指标时读到 T+1 数据 | 检查切片上下界 |
| 极值触发 | 用当日最高/最低价判断触发 | 盘中不可知，只能事后确认 |
| 财务数据回填 | 用最新一期财报回溯历史 | 必须用公告日，而非报告期 |
| 不可成交假设 | 涨停买入、跌停卖出 | 涨跌停日标记为无法成交 |
| 榜单/资金流错位 | T 日龙虎榜在 T 日使用 | 收盘后公布的数据只能 T+1 用 |

最隐蔽的是第四类。财报的"报告期"和"公告日"可能相差 1–3 个月，用报告期回填等于提前知道了未来。

## 过拟合的判定

### 样本内外切分

前 70% 选参，后 30% 只验证一次。判定阈值：

```
样本外年化 / 样本内年化 < 0.5  →  过拟合
```

衰减 50% 是经验阈值，来自大量策略的实证分布，不是理论值。样本外交易笔数 < 60 时，这个比值本身不稳定。

### walk-forward

滚动窗口，每段独立选参、独立验证。要求：

- 至少 4 段；
- 每段训练窗口 ≥ 2 年；
- 记录参数漂移，段间参数跳变 > 50% 视为不稳定；
- 拼接净值必须扣成本。

### 参数敏感性

对每个参数做 ±1 档邻域扫描。若最优点的邻域绩效断崖式下跌（邻域标准差 > 均值 50%），说明参数在拟合噪声。最优参数落在扫描边界时，真实最优可能在界外。

## 幸存者偏差

只包含今天还活着的股票，等于提前剔除了退市与暴雷样本。三种修正：

1. 用历史成分股（指数调样记录）；
2. 显式纳入已退市标的的价格序列；
3. 更名、借壳按代码跟踪，不按名称匹配。

小市值策略受这项影响最大：退市股集中在小市值区间，剔除它们会系统性抬高收益。

## 诚实的报告写法

报告第一节写自检表，绩效数字放后面。理由是读者一定会先看收益，而结论的可信度取决于自检。

不通过的项目必须写在最前面，并给出具体数字（例如"样本外衰减 62%"），不要写"略有衰减"。
