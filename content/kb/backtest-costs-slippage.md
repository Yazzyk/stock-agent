# 回测成本与滑点

成本是回测里最容易被忽略、也最容易把策略从盈利变成亏损的一项。零成本回测的数字没有参考价值。

## 成本参数表（本项目唯一口径）

| 项目 | 参数 | 说明 |
|---|---|---|
| 佣金 | 双边 0.03%，单笔最低 5 元 | 券商差异大，按最低 5 元计更保守 |
| 印花税 | 卖出 0.05% | 2023-08-28 起由 0.1% 减半 |
| 过户费 | 双边 0.001% | 2022-04-29 起沪深统一 |
| 滑点 | 单边 0.1% | 小市值、低流动性标的应上调 |

一次完整往返（买 + 卖）：

```
成本率 = 0.03% × 2 + 0.05% + 0.001% × 2 + 0.1% × 2 ≈ 0.262%
```

再叠加最低 5 元佣金：单笔 1 万元的交易，佣金按 5 元计等于 0.05%，实际成本升到 0.302%。

## 换手对年化的侵蚀

```
年成本 ≈ 单次往返成本 × 年换手次数
```

| 年换手 | 年成本（约） |
|---|---|
| 6 次 | 1.6% |
| 12 次 | 3.1% |
| 24 次 | 6.3% |
| 60 次 | 15.7% |

一个日频均线策略年换手常在 20–40 次，成本吃掉 5%–10% 年化。很多"年化 20%"的策略扣完成本只剩个位数。

## 滑点的建模方式

滑点不是手续费，是**成交价与信号价之间的差**。三种常用建模，从粗到细：

1. 固定 bp：单边 10bp，适合流动性好的大中盘。
2. 按成交额比例：`slippage = k × (下单金额 / 当日成交额)`，k 取 0.1–0.3。
3. 按盘口深度：用五档挂单量估计冲击成本，需要逐笔数据。

研究与实盘的差距主要来自第 3 项，但前两项已经能筛掉大部分不成立的策略。

## 三个具体的建模陷阱

- **同日成交**：信号用收盘价计算、成交也用收盘价，等于零滑点零延迟。
- **涨停可买、跌停可卖**：涨跌停时对手盘为零，回测里必须判定为"无法成交"或顺延到下一日。
- **最低佣金漏算**：小额高频策略的成本被系统性低估。

## 报告里必须写清的四行

1. 佣金率与最低收费；
2. 印花税方向与税率（含生效日期）；
3. 过户费率；
4. 滑点模型与参数。

缺任一行，回测结论不可比较，也无法被别人复现。成本口径一旦确定，同一批对比实验里不得更改。
