# 实盘冠军战法：选股与买卖逻辑

> 来源：B站视频《实盘赛冠军是怎么选出哈药、爱丽、云锗、有研、高争并且介入的》
> up主：勇者幻幻（实盘赛冠军），视频约 43 分钟，BV1jWuU6WEJZ
> 定位：把「市场赚钱效应」作为第一出发点 —— 先看风，再找票。

---

## 0. 总纲：三层决策 + 资金如水

1. **决策链：市场环境 ＞ 题材 ＞ 个股**。环境不对，个股再强也少做。
2. **资金像水**：永远流向「阻力最小、预期收益最大」的方向。成交量是资金流向最好的提现（指标）。
3. **赚钱效应会被模仿，亏钱效应也会被传染**：市场不断给某类风格溢价 → 资金开始模仿该赚钱效应 → 符合该效应的票走出超预期走势时买入更有信心。
4. **追强弃弱（反人性但概率占优）**：抄底=底只有一个，抄错十次错九次，本金腰斩再腰斩；追真正强势有辨识度的票=顶只有一个，追十次对九次，错的那次还不一定亏多少（甚至反包新高）。交易是概率游戏，坚持做大概率对的事。
5. **管住手是最高的风控**：市场疯狂时冷静、没机会时等待、机会出现时敢于执行。

## 1. 玩法一：反指抱团 → 指数共振 → 二波（案例：哈药股份 600664）

### 1.1 定位
首板出现在指数大阴线日（7月10日）→ 市场将其定位为「指数的反指/抱团」标的：指数跌它涨，指数修复它反而危险。

### 1.2 买点拆解
| 时间 | 事件 | 买点逻辑 |
|------|------|----------|
| 7/16 | 盘尾放量走 T 字板 | 次日预期 3% 左右高开 |
| 7/17 | 竞价 2.43 开符合预期；指数低开下杀，哈药**逆势上板走强** | 超预期买点（印证反指属性），5进6 时首次买入 |
| 7/20 | 科技早盘抢修复（中际 +5%），资金弃抱团修科技；哈药上板未封住 | 反指票在指数修复日最危险 → 7/20 地板开，此单平价离场 |
| 7/21 | 哈药**地天板** + 指数 10:11 走出最低点反转 + 中际 +13% 大阳线 | 与指数共振、打出辨识度（不再是纯反指）→ 辨识度确认 |
| 7/31 | 前一日指数大跌但未破前低 3741.1；科技杀狠（中际破 800）→ 次日科技强修复（中际 +11%）、AI 应用爆发 | 尾盘判断科技高潮次日要分歧 → 拿哈药当「爆弹」（对冲），并预期二波 |

### 1.3 加仓与做 T 逻辑（监管出清周期）
- 7/24 哈药进监管（重点监控）→ 临近出监管前通常有一波**反抽赚钱效应**（先例：深水 7/27 出监管前反抽、数源 7/28 出监管前反抽；但出监管当天即跌停）。
- 周四哈药出大阴线 = 资金提前兑现「出监管被砸」的预期（亏钱效应被传染）。
- 周五早盘哈药**主动走强**，打破亏钱效应 = 二波开始；且与走单波的爱丽形成**分离**（爱丽往下杀、哈药逆势上涨）→ 标准加仓点。
- 卖出纪律：抱团可继续加仓做 T；二波上板继续加仓；走不出二波则兑现。

### 1.4 要点
- 反指/抱团票看指数脸色：**指数修复日=反指票危险日**。
- 分离确认是最强信号：同类票下杀、该股逆势上涨 → 加仓。

## 2. 玩法二：一字首开模式（案例：爱丽家居 603221）

### 2.1 模式定义
连续一字板（重大利好：重组/资产注入/大订单）后**首次开板**的套利模式。
- 一字板 = 市场连续多天用真金白银认可逻辑（几十亿甚至几百亿封单）。
- 首次开板 = 第一次真正换手，场外资金重新评估价格。
- 赚钱本质：**赚「一致 → 分歧 → 再次确认」的钱**，关键看开板后有没有新资金继续承接。

### 2.2 环境前提（必须满足）
下跌段快要止跌时 / 横盘震荡准备向上突破时（混沌期）。
> 理由：混沌期市场难出高标辨识度，此时一字开板票 = 全场最高度 + 最高辨识度 → 环境合适时享受最高溢价。

### 2.3 筹码优势
开板日大量新增筹码**成本集中**、买入目的一致 → 短期卖压小 → 强势连续一字股首次开板充分换手后，**常开启第二波**（可套利也可做波段；大多数时间套利，逻辑足够好 + 环境足够好才做波段）。

### 2.4 操作与卖出
- 买入：竞价直接顶 / 开板承接低吸 / 回封上板打板 均可。
- 卖出：次日冲高兑现（平均 4-5 个点，卖得好 8-9 个点）。
- 反人性提醒：不要因为「涨得高」不敢买，要因为「没辨识度」不敢买。

### 2.5 案例
| 案例 | 过程 | 结果 |
|------|------|------|
| 爱丽家居 | 7/30 已放量 6000 万、尾盘剩 3 亿封单 → 次日开板预期；7/31 竞价看到不断加封单、且市场环境卡在市场底部转折节点（模式自信+五洲反馈好）→ 9 板位置竞价直接顶 | 周五竞价爱丽跌停开、哈药红开 → 资金畏监管弃单波爱丽、选多波哈药（卡位）→ 周五早盘 4-5 个点卖出 |
| 高新发展（2023/11/2，华为算力） | 一字开板后第一波 +34% | 走出大二波：开板价 46.59 → 二波最高 95.39，接近翻倍 |
| 五洲（前置案例） | 并购电机芯片资产，三个 20cm 一字板；7/27 盘口低吸或等回封打板 | 次日卖出 4-5 个点（好时 8-9 个点），极稳定 |

## 3. 玩法三：双叠加品种 · 承上启下（案例：云南锗业 002428 / 有研新材 600206）

### 3.1 发现方式
8/5 竞价：云锗 9:15 封单 17 亿+（全市场第二）、9:25 第三 → **当天竞价最超预期的一字**（消息落地=没有预期；竞价超预期才有预期差）。

### 3.2 为什么强（承上启下）
- 科技硬件换手很乱、反复消化走不出来 → 资金需要新方向。
- 消息面：中美会谈前一个月，贸易战升级博弈主旋律，反制措施存在预期。
- 云锗 = **科技上游（半导体材料）× 反制品种（稀有金属/出口管制）** → 双叠加品种是本轮最佳载体。

### 3.3 执行
- 龙头（云锗）一字太快没买到 → 打同逻辑**次强**（有研，同样双叠加）。
- 周五按计划继续加云锗；有研更早上板本想也加，但**仓位均匀分配** + 留仓加哈药 → 未加，尾盘卖云锗底仓去加哈药。

### 3.4 要点
- **龙头买不到就打同逻辑次强**；盘中第一时间同步逻辑（群里喊单）。
- 仓位均匀分配，给新机会留子弹。

## 4. 玩法四：逻辑挖掘四步法（案例：高争民爆 002827）

### 4.1 触发观察（情绪判断）
复盘习惯：把**高标断板**的票拉一个分组，看第二天走势判断市场情绪。
- 高标断板后被闷死跌停 → 锁住勇敢资金 → 市场恐慌 → 资金开始**高低切** → 低位出现新赚钱效应。
- 低切两条路径：① 老题材延续发散（重切）② 外切新题材。
- 区间观察：7/10-7/30 指数二次探底区间，涨幅榜前排全是科技（平均跌 30%+，流动性出清）→ 聪明资金流向反指抱团与「股权转让/收购类」（爱丽、五洲）→ 发现股权转让类独立于板块、靠自身基本面利好上涨，市场持续给溢价 → 该赚钱效应可模仿。

### 4.2 四步法（核心方法论）
| 步骤 | 做什么 | 口诀 |
|------|--------|------|
| ① 先找市场在奖励什么 | 研究赚钱效应在哪、钱往哪流（不研究个股先研究盘面） | 先看风再找票 |
| ② 找公司的身份变化 | 市场炒的不是现在，是未来可能变成什么。高争：西藏地矿集团无偿划转获 34% 股权、拟更名「西藏地质矿业」、主营增加矿山投资开发 | 炒题材看变化，变化越大想像越大 |
| ③ 看背后的人和资源 | 是谁接的手、为什么接手、他有什么资产。西藏地矿集团 = 西藏国资委矿业平台，手握大量矿权；8/6 回购公告：平均成本 41.8 元、约 11.5 亿（在涨停价 41.87 拿货）| 股东是入口，资产才是空间 |
| ④ 把故事变成数字 | 民爆主业稳态利润对应约 85 亿市值（有安全边际）；对比宏达（多龙铜矿）300 亿市值靠矿权重估，高争当时仅 90 亿 | 没有数字的逻辑是故事，能算出来的逻辑才有赔率 |

### 4.3 买点
- 8/5 竞价从跌停板上抢到红开 2.84 = 超预期；但**次高断板防「竞价骗炮」**（资金自救做超预期形态出货）→ 等上板再板上买。
- 8/6 高争快速上板被判断为「被爱丽带动」（爱丽秒板、定位单波独立逻辑龙头）→ 不加仓。
- 8/7 爱丽核按钮、高争出现分歧且分时有承接 → **分歧加仓点**。

## 5. 交易纪律与新手建议

- **新手三件事**：
  1. 不要一开始投入太多资金，小资金练习；先建立交易体系，再谈赚钱。
  2. 找真正懂的人学「为什么」：为什么选这个票 / 为什么现在能买 / 为什么它比另一个强 / 为什么资金选这个方向。
  3. 泡在好的交流环境里，感受盘面细节、资金切换、板块轮动、情绪冰点。
- **复盘习惯**：高标断板分组看次日走势；区间涨幅榜找资金流向与赚钱效应。
- **财富是认知的变现**：跟票赚的钱不会让你翻身，只有自己的交易能力才能。
- **风险提示**：视频内容仅供学习交流，不构成投资建议；短线交易风险极高，请独立决策、控制仓位。
