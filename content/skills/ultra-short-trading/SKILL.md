# 第零篇：道法术 — 三层维度看透盘面

> 来源：龙空龙（十三）道法术
> 核心：先悟道、再守法、后用术。有术无道，注定韭菜。

## 0.1 何为「道」— A股情绪周期的本源

道是规律、本心、市场亘古不变的运行逻辑：

| 核心规律 | 含义 |
|----------|------|
| **情绪永远在轮回** | 试错期→主升期→震荡期→退潮期，周而复始 |
| **人性永远不变** | 贪婪、恐惧、侥幸、不服输，主力利用人性收割散户 |
| **龙头断板出补涨** | 龙头断板后资金寻找同题材低位标的补涨 |
| **龙头跌停出新周期** | 旧龙头彻底死亡，新周期才能干净启动 |
| **中位穿越九死一生** | 退潮期中位股夹心层，成功率极低 |

> **龙在周期在，龙亡周期断** — 这就是A股不变的道。

## 0.2 何为「法」— 交易规则与心法

| 法则 | 内容 |
|------|------|
| **天时为先** | 任何买卖先看情绪周期位置，高潮不追高，退潮不猛干 |
| **地利为辅** | 做主线、做最强题材，不做杂毛、不做边缘小题材 |
| **人和为核** | 只做龙头、只做前排、只做资金合力标的 |
| **风控为底线** | 分仓控仓、错了就止损、看不懂就空仓 |

## 0.3 何为「术」— 实战技巧

术是工具，用来执行道和法：
- 分辨日内分歧转一致，抓日内封板买点
- 识别跨日弱转强，抓龙头隔日拐点
- 看懂竞价强弱，预判隔日情绪溢价
- 分辨真假龙头、主线与杂毛
- 看懂炸板是良性换手还是资金出逃

## 0.4 出手前三层自问

```
问道：现在处于情绪哪个阶段？逆周期还是顺周期？
问法：是不是主线？是不是龙头前排？仓位是否合规？
问术：盘口有没有超预期？分歧转一致还是弱转强？竞价量能是否健康？
三层全部过关，再动手；任何一层不合规，一律放弃。
```

# 第一篇：周期择时 — 龙空龙战法

> 核心理念：**龙 — 空仓 — 龙**。只在龙头上赚钱，其余时间空仓等待。
> 来源：龙空龙（一）（二）（七）（十）（二十）

## 1.1 情绪周期本质

情绪周期的本质，是市场参与者"贪婪"与"恐惧"的循环交替，由三大因素驱动：
- **资金驱动**：增量资金入场推升乐观情绪，存量博弈引发恐慌
- **消息刺激**：政策、行业新闻快速放大群体情绪
- **赚钱效应**：前期赚钱效应吸引跟风追涨形成正反馈；后期亏钱效应触发集体出逃形成负反馈

核心逻辑是**群体非理性** — 散户受情绪传染形成一致预期：乐观时集体追涨，恐慌时集体杀跌。

## 1.2 市场周期四阶段（基础框架）

| 周期阶段 | 特征 | 核心策略 | 仓位 |
|----------|------|----------|------|
| **主升期** | 大盘配合、板块联动、赚钱效应扩散 | 重仓龙头，分歧选强，强更强 | 8-10成 |
| **混沌期** | 轮动快、持续性差、追涨杀跌最亏钱 | 确定性+超预期，无机会就空仓 | 0-3成 |
| **退潮期** | 跌停潮、炸板率高、板块批量调整 | 完全空仓，不接飞刀 | 0（强制空仓）|
| **回暖期** | 跌停家数＜5，冰点后杀不动 | 弱转强战法，最强活口突围 | 3-5成 |

## 1.3 情绪周期极简划分（两阶段法）

> 来源：龙空龙（二）— 更简洁实用的划分方式

| 阶段 | 启动节点 | 核心策略 | 仓位 |
|------|----------|----------|------|
| **低位试错期** | 旧龙头断板次日 | 小仓试错1-3板节点票，优先级：二进三＞一进二＞首板 | 1-3成（冰点可5成） |
| **主升阶段** | 破局龙打破空间压制 | 重仓介入破局龙，同时布局低位补涨标的 | 5-10成 |

**试错期核心纪律：**
- 身位优势是核心逻辑，高位节点票辨识度更高
- 结合龙头断板当日强势题材，优先题材贴合度高的标的
- 做错往往就是大面，切勿重仓押注单一标的

**主升期核心纪律：**
- 破局龙确认后可重仓介入
- 所有连板高度低于破局龙的标的沦为"中位股"，九死一生，坚决不碰
- 大题材破局龙打开更大空间，小题材破局龙可能仅1-2日溢价

## 1.4 七阶段情绪周期（精细版）

> 来源：龙空龙（七）— 比四阶段更精细的实操框架

| 阶段 | 市场特征 | 核心操作 | 仓位 |
|------|----------|----------|------|
| **启动阶段** | 龙头1-2板无持续性，题材轮动快，炸板率≥30% | 打首板（10:30前）或空仓等2板定龙头 | 1-3成 |
| **确认阶段** | 首板炸板率＜20%，出现换手2-3板龙头，板块3-5家涨停 | 打2板或3板，锁定龙头等发酵 | 3-4成→5成 |
| **发酵阶段** | 龙头3-5板，板块涨停≥8家，跟风龙连板，补涨出现 | 打龙头放量换手3板，做板块补涨 | 5-7成 |
| **加速阶段** | 龙头5-7板缩量加速，情绪狂热，卡位龙出现 | 坚定持有，卡位龙打板，6-7板逐步减仓 | 6-7成→递减 |
| **分歧阶段** | 龙一断板，炸板潮涌现，亏钱效应明显 | 龙头首阴低吸（温和断板），高低切 | 3-5成 |
| **反包阶段** | 龙一尝试反包，逆反龙酝酿 | 龙头首阴低吸博弈反包，小仓试错逆反龙 | 2-3成 |
| **退潮阶段** | 龙头阴跌，补涨龙A杀，跟风补跌 | 空仓或龙回头低吸（调整3-5天跌幅10-20%） | 0-1成 |

### 各阶段核心禁忌

| 阶段 | 禁忌 |
|------|------|
| 启动期 | 不做中位股、不追高、不做杂毛 |
| 确认期 | 拒绝缩量一字板，只做市场选出来的龙头 |
| 发酵期 | 不做支线题材、不做无辨识度跟风 |
| 加速期 | 警惕一致预期后的分歧，不追高位缩量板 |
| 分歧期 | 不切早（龙头未断板不埋伏中位股）、不切错（不做孤立票） |
| 反包期 | 不重仓博弈，即使反包成功也不贪多 |
| 退潮期 | 不抄底跟风龙，补仓龙不做首阴 |

## 1.5 节点择时 — 四大节点

> 来源：龙空龙（二十一）— 天时：题材出现的时机

| 节点 | 规律 | 操作 | 逻辑 |
|------|------|------|------|
| **龙头断板节点** | 龙头断板出补涨 | 次日1-3板节点票是补涨候选 | 资金从高位流向低位 |
| **龙头跌停节点** | 龙头跌停出新周期 | 旧周期结束，关注新题材首板 | 资金从老题材流向新题材 |
| **破局节点** | 突破空间压制 | 满仓all in位置 | 情绪到极致的体现 |
| **大盘共振节点** | 指数大阳+题材共振 | 择机参与，效果不如前三类 | 市场情绪修复信号 |

**补涨龙高度规律：** 补涨龙高度 ≈ 龙头的50%-70%，上下一个板容错。

## 1.6 分歧选强 + 弱转强战法（核心战法）

> 来源：龙空龙（十二）— 分歧转一致与弱转强的本质区别

### 核心区别（时间维度）

| 信号 | 时间维度 | 解决问题 | 买点类型 |
|------|----------|----------|----------|
| **分歧转一致** | 日内（当天盘中） | 当日龙头能否封板 | 日内买点 |
| **弱转强** | 跨日（前一日弱→次日强） | 龙头能否延续连板 | 跨日买点 |

### 弱转强触发条件（全部满足才出手）
1. 连续情绪退潮 2天以上
2. 杀不动了（冰点确认：竞价跌停＜5家）
3. 热门板块/主线
4. 个股当天**主动分歧**（非大盘被动拖累）→ **真弱势**（爆量、烂板）
5. 次日**超预期强势**：竞价高开1%-5% + 竞价量能≥前日8%-10% + 10分钟内封板 + 板块联动

### 假弱转强识别（坚决规避）
- 前一日是"被动弱势"（大盘暴跌跟风走弱），次日小幅高开反弹 → 被动修复，不是弱转强
- 次日竞价高开但量能不足（＜前日5%），开盘快速回落 → 竞价诱多
- 次日封板但封单极小、反复开板、板块无跟随 → 孤龙伪强
- 退潮期弱转强但题材已走弱 → 逆势伪强，资金自救

### T字板日内的弱转强识别
```
连续一字缩量后第3板：涨停开→砸板→回封
砸板深度＜5%（浅砸）→ 3分钟内回封 → 回封后全天无抛压
→ 这是"分歧换手洗盘"，不是出货
→ 判断：该弱不弱视为强 → 次日大概率高开加速
```

## 1.7 混沌期四不原则
1. **不冲天炮**：不去接力前排缩量秒板
2. **不接一致延续**：板块爆发次日不追高
3. **只做充分换手**：前排辨识度+抗住分歧+二次进攻活口
4. **冲高不贪**：不能涨停/分时不够力度立即走人

## 1.8 板块健康度判断

| 健康信号 | 风险信号 |
|----------|----------|
| 高位主动走强 → 带动低位补涨 | 低位补涨但高位涨不动（掩护出货）|
| 中位股首次集体加速 → 板块当天爆发 | 中位股掉队 |
| | 板块批量跌停 |
| | 利好多的板块反而是弱 |

## 1.9 每日核查清单

**盘前**：[ ] 当前什么周期？ [ ] 大盘有无风险？ [ ] 今天什么策略？ [ ] 目标股有板块配合吗？

**盘中**：[ ] 竞价跌停家数（＞5不出手） [ ] 炸板率高吗？ [ ] 是分歧后弱转强吗？ [ ] "没有持仓我会买吗？"

**盘后**：[ ] 按计划执行了吗？ [ ] 有无模式外操作？

# 第二篇：选股审美 — 四层过滤法 + 论资排辈

> 核心原则：**周期 ＞ 板块 ＞ 个股 ＞ 盘口**
> 来源：龙空龙（四）（十八）（十九）

## 2.1 四层过滤框架

```
周期 → 做不做？（定仓位+策略）
  ↓
板块 → 在哪做？（定方向）
  ↓
个股 → 做哪个？（定目标）
  ↓
盘口 → 什么时候动手？（定时机）
```

## 2.2 第一层：定位市场情绪周期

| 周期 | 策略 | 操作 |
|------|------|------|
| **启动期** | 寻找与指数共振的新题材 | 首板 或 1进2 领涨股 |
| **主升期** | 聚焦市场最强主线 | 龙头 或 主线内补涨龙 |
| **分歧期** | 主线内低位切换 / 新过渡题材 | 首板 或 1进2 |
| **退潮期** | 空仓或极小仓位试错 | **绝对回避中高位股** |

## 2.3 第二层：筛选最强主线板块（四要素）

| 要素 | 标准 |
|------|------|
| **梯队完整** | 高标→中位→低位完整，有龙头/中位连板/首板助攻 |
| **容量人气** | 能容纳大资金+持续热度，论坛/媒体热议 |
| **逻辑支撑** | 政策/事件/业绩驱动，硬逻辑非纯消息炒作 |
| **持续性** | 连续多日活跃，非一日游 |

**题材优先级：** 现象级题材 ＞ 政策级题材 ＞ 行业级题材 ＞ 个股单独利好

**持续性判断标准：** 新题材承接老题材结束节点，连续两日发酵，第二天稳定走出2板梯队，第三天继续晋级 = 真持续性。单日爆发、无梯队、无晋级 = 一日游。

## 2.4 第三层：个股四维打分 + 论资排辈

### 个股地位六层级（论资排辈）

> 来源：龙空龙（十八）— 看懂江湖辈分，方能进退自如

| 层级 | 身份 | 特征 | 操作策略 |
|------|------|------|----------|
| **第一层级** | 中军龙 | 板块内市值最大、成交最高、流动性最好的权重核心 | 托底题材，不一定天天涨停，但不崩板块就有底气 |
| **第二层级** | 情绪周期龙头 | 连板高度最高、带动性最强、情绪优先级最高 | 核心操作标的，重仓出击 |
| **第三层级** | 先锋龙 | 旧周期中提前走出高度、打出辨识度的中位股 | 新周期龙头买不进时的第二确定性机会，可低吸 |
| **第四层级** | 普通补涨龙 | 龙头断板后卡位的低位标的 | 高度≈龙头50%-70%，一波流，见顶即走 |
| **第五层级** | 中位跟风 | 身位低于龙头，无独立带动性 | 退潮期比龙头跌更快，不值得格局 |
| **第六层级** | 后排杂毛 | 无辨识度、无资金承接 | 一律放弃 |

### 地位优先（最重要）
| 类型 | 定义 | 时机 |
|------|------|------|
| **龙头** | 市场总龙头/板块龙头 | 确认后介入 |
| **补涨龙** | 龙头断板时，第一个强势涨停的低位板 | 龙头分歧日 |
| **日内先锋** | 板块分歧转一致时，最先上板带情绪 | 当天上车 |
| **先锋龙** | 旧周期提前走出高度的中位股，新周期被动升级 | 新周期确认后低吸 |

### 龙头必备气质（四大特征）
1. **带动性**：上板动作主动，同板块最先涨停，它一动板块跟风集体跟进
2. **抗跌性**：高举高打，分歧时高位震荡不跳水，分歧次日有资金承接
3. **情绪韧性**：大分歧后往往走出超预期走势，多次打破市场悲观预期
4. **高辨识度**：连续走强打出市场人气，各平台讨论度居高不下

### 选股三标准（天时地利人和落地）

> 来源：龙空龙（十九）

**1. 流通市值适中：** 优先20-100亿实际流通。太小易被控盘，太大难连板。

**2. 历史股性活跃：** 近一个月出现过涨停，有连板基因，资金认可度高。

**3. 筹码结构健康：**
- 避开近期K线有明显放量高点的个股（历史套牢盘重）
- 警惕首板、二板直接顶一字的标的（筹码交换不充分，全是获利盘）
- 优选首板、二板充分换手、甚至爆量的个股（筹码清洗彻底）

### 筹码与形态
- ✅ 股性活跃：历史连板记录、涨停次日有溢价
- ✅ 筹码干净：前方无密集套牢盘，近期换手充分
- ✅ 形态突破：平台突破或关键位置突破

### 盘口信号
- 涨停时间早 → 越早地位越高
- 封单质量高 → 封板坚决，抛压小
- 有带动性 → 涨停后带动同类/板块上涨
- **分离确认** → 龙头跳水时逆势回封 ← 最强信号

## 2.5 第四层：盘口确认

1. 定板块 → 主线确认
2. 筛个股 → 从当日首板中找次日可晋级的
3. 看地位 → 涨停早、分时流畅的"硬板"
4. 看逻辑 → 优选叠加概念
5. 看筹码 → 排除一字板，优选换手充分的
6. 看分离确认 → 龙头跳水但该股逆势回封 → 提高优先级

## 2.6 放弃的艺术

| ❌ 绝对排除 | 原因 |
|------------|------|
| 非主线杂毛 | 再好的形态也不参与 |
| 中位尴尬股 | 退潮/强分歧期，3板4板是"死亡地带" |
| 缩量加速板 | 一字板上来的，开板即巨量抛压 |
| 跟风后排股 | 龙头涨停半小时后才跟风，次日溢价有限 |
| 穿越龙 | 中位股高度超过龙头，九死一生，历史仅2只成功 |

# 第三篇：量价打板 — 量化风控体系

> 核心理念：将"个股强弱"和"筹码好坏"，转化为可量化数据。
> 来源：龙空龙（六）（十七）

## 3.1 竞价金额计算

```
理想竞价成交额 = 昨日成交额 × 目标换手率（3%-8%）
```

### 按个股地位分三档

| 类型 | 竞价金额要求 | 高开要求 |
|------|-------------|----------|
| **总龙头/高度板** | ≥1.5亿（一字板参照） | 强势高开/一字 |
| **主线身位股/人气股** | ≥昨日成交额×16% | +5%以上 |
| **轮动套利股** | ≥昨日成交额×6% | +5%以上 |

### 竞价判断速查

| 竞价/昨日成交 | 高开幅度 | 判断 |
|---------------|----------|------|
| ≥16% | +5%以上 | ✅ 实强，资金主动进攻 |
| 10-16% | +3%~+5% | 🟡 偏强，需观察 |
| 5-10% | +0%~+3% | 🟡 一般，谨慎 |
| <5% | 任何 | ❌ 虚高/无量，放弃 |

## 3.2 涨停次日竞价预期体系

> 来源：龙空龙（六）— 按封板时间定高开预期 + 竞价量能标准 + 6种竞价组合

### A. 按封板时间定高开预期

| 封板时间 | 不及预期 | 符合预期 | 超预期 |
|----------|----------|----------|--------|
| **一字板** | 高开＜6% | 6%-9% | ＞9%/再一字 |
| **9:45前涨停** | 高开＜4% | 4%-6% | ＞6% |
| **9:45-11:30涨停** | 高开＜2% | 2%-4% | ＞4% |
| **13:00-14:00涨停** | 低开＜0% | 0%-2% | ＞2% |
| **14:00-15:00涨停** | 低开 | 平开 | 高开＞0% |

### B. 竞价量能标准（最核心）

**竞价量 ÷ 昨日总成交额：**
- 昨日成交2-5亿：竞价量 ≥ 10%
- 昨日成交5-10亿：竞价量 ≥ 8%-10%
- 昨日成交10-20亿：竞价量 ≥ 5%-8%
- **简化记忆：10亿以下≥10%合格，10亿以上≥8%合格**

> **口诀：竞价量不够，高开也白凑；量能达标，溢价才稳。**

### C. 六种竞价组合（直接对应操作）

| 组合 | 表现 | 解读 | 操作 |
|------|------|------|------|
| **C1: 价超量足** | 高开＞预期2% + 竞价量达标 | 资金抢筹意愿极强，连板核心信号 | 情绪上升期直接竞价加仓/打板 |
| **C2: 价超量少** | 高开＞预期2% + 竞价量远低标准 | **典型诱多陷阱**，无真实资金承接 | 坚决不追高，持有仓位竞价止盈 |
| **C3: 价合量足** | 高开在预期区间 + 竞价量达标 | 多空博弈平稳，看开盘承接 | 观察5分钟，放量上攻持有，缩量滞涨减仓 |
| **C4: 价合量少** | 高开在预期区间 + 竞价量不足 | 资金接力意愿弱，被动维持高开 | 竞价止盈部分，不能快速放量拉升则清仓 |
| **C5: 价不及量足** | 低开/平开 + 竞价量达标 | 资金出逃但有承接，可能洗盘/换庄 | 先减仓，快速翻红放量可接回 |
| **C6: 价不及量少** | 低开 + 竞价量远低标准 + 绿柱压顶 | **最危险组合**，资金彻底出逃 | 竞价直接核按钮清仓，绝不幻想 |

**终极口诀：**
> 价超量足大胆拿，价超量少是诱多；
> 价合量足看承接，价合量少先落袋；
> 价不及量足看修复，价不及量少直接跑。

## 3.3 涨停瞬间换手要求

```
涨停瞬间最低成交额 = 基准日成交额 × 动态换手系数
```

**基准日选取规则**：取最近一个"充分换手日"（非一字板日）的成交额为基准。

### 系数根据筹码压力调整

| 个股类型 | 系数 | 说明 |
|----------|------|------|
| **连续缩量加速龙头** | **2-3倍** | 获利盘未释放，必须巨量换手 |
| **面临前高套牢盘** | **70-80%** | 除获利盘外还有历史套牢盘 |
| **逻辑存疑/跟风轮动** | **50-60%** | 至少半数筹码换手，底线风控 |

> ⚠️ 系数低于50% → 换手不充分 → 封板不可靠 → 直接放弃

## 3.4 隔日量能模型 + 炸板量能量化标准

> 来源：龙空龙（十七）— 成交量终极实战

### 四大隔日量能模型

| 模型 | 量能特征 | 次日操作 |
|------|----------|----------|
| **温和放量换手板** | 量能=前日1.2-1.8倍，换手充分，盘中烂板回封 | ✅ 可低吸、半路、打板（模式内主做） |
| **缩量加速板** | 量能＜前日0.5倍，几乎无换手，一字/秒板 | ❌ 绝对不打板！最高概率大面战法 |
| **爆量烂板/天量滞涨** | 量能≥前日2.5倍，反复炸板，换手超大 | ❌ 次日一律放弃，90%概率低开下杀 |
| **缩量弱势烂板** | 量能＜前日0.5倍 + 烂板 | ❌ 直接淘汰，删除自选 |

### 炸板量能量化标准

**炸板放量倍数 = 当日炸板后全天成交量 ÷ 前一日涨停成交量**

| 位置 | 健康炸板（可接力） | 危险炸板（不接力） |
|------|-------------------|-------------------|
| **低位1-2板** | 放量1.2-2倍，换手＜35%，快速回封 | 放量≥2.5倍，换手＞40%，反复烂板 |
| **中位3-4板** | 放量1.1-1.5倍，换手＜30%，10分钟内回封 | 放量≥2倍，换手＞35%，回封无力 |
| **高位4板以上** | 放量1.3-1.8倍，换手30%-40%，半小时内回封 | 放量≥2倍，换手＞45%，不回封/尾盘回封 |

**终极炸板口诀：**
> 低位炸板≤2倍可试错，≥2.5倍放弃；
> 中位炸板≤1.5倍可接力，≥2倍不打板；
> 高位炸板≤1.8倍轻仓，≥2倍清仓/不接力；
> **核心红线：任何位置炸板≥2.5倍，一律不接力，99%是出货。**

## 3.5 T字板专项分析

| 特征 | 洗盘T字（看多） | 出货T字（看空） |
|------|---------------|---------------|
| 开板深度 | ＜5%（浅砸） | ＞7%（深砸） |
| 回封时间 | ＜5分钟 | 反复开合/尾盘才封 |
| 回封后抛压 | 几乎无成交 | 持续有卖盘 |
| 全天换手 | 集中在开板时段 | 全天分散 |
| 结论 | 主力洗获利盘，看涨 | 主力出货，看跌 |

## 3.6 打板决策链条

```
竞价金额达标？ → ✅ → 高开匹配？ → ✅ → 板块助攻？ → ✅ → 涨停换手达标？ → ✅ → 打板
                ↓ ❌                    ↓ ❌               ↓ ❌                ↓ ❌
               放弃                    放弃               放弃                放弃
```

## 3.7 打板前速查卡

| 检查项 | 标准 |
|--------|------|
| 个股地位 | 龙头/身位/跟风？ |
| 昨日成交额 | 多少亿？基准日成交额多少亿？ |
| 竞价成交额 | ≥昨日成交×目标% / 一字板参考1.5亿 |
| 竞价量能 | 10亿以下≥10%，10亿以上≥8% |
| 高开幅度 | 匹配个股地位？匹配封板时间预期？ |
| 板块助攻 | 小弟涨停跟随？ |
| 涨停时换手 | ≥基准日成交×系数 |
| 昨日量能模型 | 温和放量✅ / 缩量加速❌ / 爆量烂板❌ |
| T字板质量 | 开板深度＜5%? 回封时间＜5分钟？回封后无抛压？ |
| 市场情绪 | 跌停家数＜5？炸板率＜30%？ |

全部 ✅ 才动手。

# 第四篇：题材见顶信号

> 短线题材的"顶"不是精确的K线点，而是一个区域——靠信号簇共振判断。
> 来源：龙空龙（九）（二十）

## 4.1 一级警报：确认见顶（出现就该果断减仓/离场）

### 总龙头见顶信号
- **高位爆量炸板**：连续缩量加速后，放天量（约前期2倍以上），封不住涨停，收长上影/大阴线
- **跌破短线生命线**：收盘价连续两日有效跌破5日线，再破10日线 → 趋势性质变了
- **分时出货特征**：涨停板上反复烂板回封无力、钓鱼线/直线跳水、尾盘竞价被砸

### 亏钱效应扩散（最客观的风控指标）
- **高位股批量跌停**：3只以上前期高标跌停，或跌停家数≥10家且多为近期热门题材股 → 退潮确认
- **炸板率飙升**：封板率跌到70%以下（正常＞80%），炸板后直线跳水、"天地板"出现
- **连板高度骤降**：前期7-8板 → 快速压到3-4板甚至2板，新高度板活不过3天

### 板块内部结构瓦解
- **龙头滞涨 + 跟风先崩**：龙头横盘，龙二龙三、中位股（3-6板）已开始连续大跌/跌停 → 最前置的预警
- **"毕业照"信号**：龙头涨不动了，垃圾股/沾边股/ST突然群起补涨 → "人都到齐拍完照了，该散了"
- **补涨龙高度递减**：补涨高度从5板→3板→2板，次日毫无溢价
- **小弟卡大哥**：板块小弟开盘比龙头更强 → 板块见顶信号

## 4.2 旧周期死亡确认信号（满足3条即可定论）

> 来源：龙空龙（九）

1. 总龙头放量跌停/天地板/一字跌停，连续2日以上A杀，封单持续加大无有效撬板
2. 高位跟风集体崩盘：中位股、后排跟风股批量跌停、核按钮，连板股大面积断板
3. 连板高度快速压缩：最高连板从7-8板压缩至2-3板，连板梯队彻底断层
4. 盘面数据极端恶化：跌停家数远超涨停家数，炸板率突破40%-50%

## 4.3 新周期启动前兆信号

1. 旧龙头跌势衰竭：不再连续跌停，缩量阴跌、撬板企稳
2. 新题材逆势异动：首板逆势涨停，板块内多只同步响应，独立于旧题材
3. 高标弱转强穿越：独立高标次日弱转强，拒绝跟随旧龙杀跌
4. 盘面数据边际好转：涨停家数回升，炸板率下降，跌停家数减少

## 4.4 二级预警：顶部区域（还没确认，但必须收缩防线）

| 信号 | 表现 |
|------|------|
| **量价背离** | 板块/龙头价还能新高，但成交量萎缩，追高资金乏力 |
| **高低切换失效** | 资金想做低位补涨，但补涨股涨停次日没溢价 |
| **新题材抽血** | 突然出现逻辑更新鲜的题材，资金批量迁移 |
| **利好兑现变利空** | 关键催化靴子落地后，高开低走放量大跌 |
| **监管施压** | 交易所关注函/重点监控/停牌核查密集出现 |
| **情绪狂欢极致** | 全民讨论、"闭眼买都能赚"的氛围 |

## 4.5 每日30秒复盘检查

**盘后三问：**
1. **龙头今天什么状态？** — 封住？烂板？断板收阴？跌停？
2. **亏钱效应多少？** — 跌停几家？炸板率多少？昨涨停今日溢价如何？
3. **梯队还在不在？** — 连板高度有没有断层？中位股有没有批量闷杀？

**竞价9:25确认（次日最关键）：**
- 昨日高位标的是核按钮低开还是有承接？核按钮=退潮确认，当天别接力
- 龙头竞价封单大幅缩水或反复撤单 → 警惕诱多

## 4.6 最容易踩的坑

| 错误 | 正确做法 |
|------|----------|
| 把"分歧"当"见顶" | 龙头爆量分歧但收阳、中军没破位、跌停≤2家 → 还能回流修复 |
| 把"见顶"当"分歧" | 高位批量跌停才信，已A字杀。龙头断板+中位跌停+炸板飙升三重共振 = 逃命 |

> **一句心法：分歧看龙头承接，见顶看亏钱扩散。**

# 第五篇：核心买点体系

> 来源：龙空龙（八）（十二）（十九）

## 5.1 唯一性买点

当某只标的在情绪周期某个节点成为「唯一」核心标的时，资金没有其他选择，只能抱团，享受隔日溢价。

### 空间唯一 — 剩者为王
多只不同题材节点票PK，某只打败所有候选，成为周期内唯一空间龙头，第一次确立身位优势时 = 空间唯一性买点。

**案例**：深华发A vs 华电辽能同5板PK，次日深华发开板下杀至跌停，华电辽能主动承接回封 → 空间唯一性确立。

### 板块唯一 — 龙头角逐战
同题材多只同身位标的角逐板块龙头，某只胜出确立板块唯一地位 = 板块唯一性买点。

**案例**：双鹭药业/津药药业/联环药业同2板，次日津药药业晋级3板，其余全天无摸板动作 → 板块唯一性确立。

## 5.2 四大实战买点

> 来源：龙空龙（十九）

### 买点1：2进3试错买点
- 题材连续发酵两天、具备想象空间
- 个股身处板块前排、筹码结构健康
- 在三板板上直接试错建仓

### 买点2：分歧半路买点
- 板块或大盘分歧，龙头炸板回落
- 观察承接：炸板后20分钟以上，股价稳定在+5%上方、运行在分时均价线之上
- 没有破位跳水 = 优质半路买点

### 买点3：弱转强买点
- 标的前一日爆量分歧、收大烂板
- 次日开盘快速修复、再度上板
- 两种思路：分歧后承接有力半路低吸（空间更大）/ 分歧转一致封板确认（确定性更高）

### 买点4：破局买点
- 一轮主升结束，龙头断板，市场连板高度被压制
- 当周期内最后一只中位股止步晋级，该位置 = 下一轮周期破局节点
- ⚠️ 当前市场6板以上高位破局一律不参与

## 5.3 龙头断板后操作规则

> 来源：龙空龙（十九）（二十）

| 场景 | 操作 |
|------|------|
| 龙头断板当日 | 第一时间减仓（至少50%） |
| 断板次日跌停 | 无条件清仓离场，不抱幻想 |
| 断板次日未跌停有承接 | 深水区低吸、冲高止盈，滚动做T，直到题材行情结束 |
| 断板后反包秒板 | 有概率走成妖股，可格局但需灵活 |
| 老龙落幕后 | 可布局补涨龙，牢记补涨龙高度受限（龙头50%-70%），不盲目格局 |

**板块回流时间规律：** 龙头跌停后，板块回流一般出现在第三天；极端行情（如商业航天）连续杀跌五天，亏钱效应彻底释放才修复。

# 第六篇：综合实战案例

## 案例1：美利云 000815 分析示范

### 背景
- 7/20: 首板一字涨停 13.33
- 7/21: 二板一字涨停 14.66

# 第七篇：五维识龙法 — 从百只首板中锁定主升龙头

> 来源：淘股吧"喜羊羊勇闯草原"实战干货

## 7.1 总框架：情绪 → 节点 → 布局 → 选股 → 找龙

```
情绪（能不能做？容错率高不高？）
  ↓
节点（资金聚焦哪个梯队？）
  ↓
布局（主力在哪个梯队在布局？）
  ↓
选股（盘子、股价、股本、股性哪个好？）
  ↓
找龙（辨识度动作：让/卡/指引/弱转强）
```

## 7.2 第一维：情绪 — 开仓容错率的裁判

| 指标 | 看什么 | 好（可开仓） | 差（不开仓） |
|------|--------|------------|------------|
| **断板反馈** | 前一天断板的中高位票 | 红K/弱转强/反包 → 减亏机会 | 负反馈/A杀/跌停 → 谁敢接力？ |
| **异动态度** | 进10天100%异动的票 | 继续强势 → 下面梯队跟上 | 直接负反馈 → 6进7抢跑 |
| **辨识度开盘** | 题材最强辨识度 | 符合预期（该一字的一字） | 不一字/低开 → 小弟恐慌踩踏 |

## 7.3 第二维：节点 — 让资金自动聚焦

| 节点类型 | 触发事件 | 效果 |
|----------|---------|------|
| 高位断板节点 | 龙头断板/放量 | 资金找补涨，同属性首板预期增强 |
| 大盘共振节点 | 大盘大阳/冰点反转 | 与指数共振的梯队辨识度最高 |
| 龙头反包节点 | 断板龙头反包涨停 | 确认题材未死，下面梯队续命 |
| 个股穿越节点 | 退潮期抗跌活口 | 回暖时最先被资金选中 |

**捆绑效应：** 龙头超预期→利好补涨；补涨强势→给龙头续命；龙头断板→补涨高度被锁死。

## 7.4 第三维：布局 — 识别主力操盘痕迹

| 手法 | 含义 | 识别特征 |
|------|------|---------|
| 地域陪跑 | 龙头+同省份多只跟风 | 同一省份的票同时异动 |
| 梯队药箱 | 同题材不同身位的票同时布局 | 高标+中位+首板同时有异动 |
| 产业链批量 | 同一主力多只票联动 | 分时走势高度同步 |

## 7.5 第四维：选股 — 四个硬指标筛选

| 指标 | 优选 | 劣选 | 逻辑 |
|------|------|------|------|
| **盘子** | 20-50亿市值 | 200亿+ | 小盘控盘成本低，高度取决于资金意愿 |
| **股价** | 3-10元 | 70元+ | 3元翻倍才6块，70元翻倍到140谁接？ |
| **股性** | 历史连板+次日溢价 | 一进二就爆头/大阴线 | 里面明显有"坏东西" |
| **股本** | 股本干净集中 | 股本细碎分散 | 股本细碎→爆量→控盘成本大增 |

## 7.6 第五维：找龙 — 四个辨识度动作

| 动作 | 含义 | 识别特征 |
|------|------|---------|
| **让** | 高位票主动温和断板，把地位让给低位票 | 高位断板但不跌停，保持红K，同题材低位出现强势标的 |
| **卡** | 换手标的在顶一字标的炸板时抢先上板 | 一字板炸板瞬间，换手板逆势回封 |
| **指引** | 首板中出现新增一字板，为前排引路 | 昨日没有，今日突然出现同题材一字板，竞价大单封死 |
| **弱转强** | 题材分歧日弱势，次日超预期强势开盘 | 前一天分歧/弱势，次日超预期高开+3%以上，快速脱离分歧区 |

## 7.7 五维联动：实战筛选流程

```
每天首板几十只
  ↓ 第一维：情绪好不好？
  不好 → 空仓看戏
  好 ↓
  ↓ 第二维：今天什么节点？资金聚焦哪个梯队？
  ↓ 第三维：哪个梯队有布局痕迹？
  ↓ 第四维：该梯队里哪个票盘子小+股价低+股本好+股性好？
  ↓ 第五维：有没有辨识度动作？（让/卡/指引/弱转强）
  ↓
锁定主升候选 → 结合量价打板体系量化确认 → 执行
```

# 第八篇：大小周期嵌套 — 题材与龙头的共生共衰

> 来源：淘股吧"喜羊羊勇闯草原"

## 8.1 核心概念

| 概念 | 定义 | 作用 |
|------|------|------|
| **大周期** | 主线题材从无到有、从盛到衰的完整生命周期 | 决定赚钱效应天花板、资金容错率 |
| **小周期** | 龙头个股从启动到退潮的情绪轮回 | 决定具体买卖节奏 |

> **一句心法：大周期向上，龙头的分歧是低吸窗口；大周期向下，龙头的反弹是诱多陷阱。**

## 8.2 题材三分法

| 题材类型 | 定义 | 与大周期的关系 |
|----------|------|---------------|
| **主线题材** | 强驱动+大容量+高共识 | 赚钱效应核心，决定大周期高度 |
| **伴生题材** | 上下游/补涨/概念扩散 | 依附主线，赚钱效应延伸 |
| **敌对题材** | 资金跷跷板另一方 | 存量博弈，与主线此消彼长 |

## 8.3 大周期五阶段

| 阶段 | 主线 | 伴生 | 敌对 | 核心信号 |
|------|------|------|------|---------|
| **启动期** | 少量先锋涨停，板块效应弱 | 无联动 | 仍是流动性核心 | 先锋连板打出赚钱效应 |
| **发酵确认** | 连续涨停潮，梯队完整 | 上下游启动补涨 | 缩量阴跌，资金流出 | 板块成交量占比大幅提升 |
| **高潮加速** | 缩量批量涨停，无差别上涨 | 全线高潮，补涨龙频出 | 冰点，无反抗 | 无差别上涨 = **见顶前置信号** |
| **分歧衰退** | 分化严重，高位滞涨 | **率先崩盘A杀** ← 最前置预警 | 资金回流反弹 | 伴生先崩 + 龙头首次巨量分歧 |
| **退潮冰点** | 批量跌停A杀，反弹无力 | 全面崩塌 | 成为新主线 | 龙头无修复，亏钱效应扩散 |

> ⚠️ **伴生题材先崩是最前置的退潮信号**，比龙头见顶还早！

## 8.4 实战核心：周期共振 vs 周期背离

| 场景 | 信号 | 操作 |
|------|------|------|
| **周期共振** | 大周期向上 + 小周期分歧 | 最佳低吸/接力窗口，容错率最高 |
| **周期背离** | 大周期向下 + 小周期一致 | 诱多陷阱，容错率极低，极易A杀 |

# 第九篇：量化环境生存法则 — 与机器共舞

> 来源：淘股吧"喜羊羊勇闯草原"

## 9.1 量化的五大碾压优势

| 特征 | 表现 | 对散户的影响 |
|------|------|------------|
| **零情绪** | 无贪婪/恐惧/犹豫，只执行策略 | 机器不会扛单，你会 |
| **毫秒速度** | 挂单→撤单→成交瞬间完成 | 你还在反应，它已做完一轮 |
| **批量操作** | 同一策略覆盖几十上百只标的 | 板块集体拉升可能是量化在造局 |
| **多策略覆盖** | 同时埋伏上涨/下跌/轮动/反转 | 不管盘面怎么走它都有预案 |
| **压缩周期** | 大周期→小周期→日内级别 | 上午启动、下午高潮、次日退潮 |

## 9.2 对抗量化三招

### 招一：前置资金逻辑 — 站在量化前面想
推演链条：资金想要在A日做什么 → 需要在A-1日做什么来铺垫 → 需要在A-2日做什么来造势 → 你在A-2日/A-1日就埋伏进去

### 招二：跑在量化前面 — 识别超预期/不及预期

| 场景 | 信号 | 动作 |
|------|------|------|
| **不及预期** | 该开大单一字的没开出/20分撤单严重/板块龙头开在水下 | 🔴 竞价就卖，跑在量化前面 |
| **超预期** | 20分后封单持续增加/板块集体一字超预期/跟风封单反超龙头 | 🟢 找弹性套利/最强换手跟随/可转债套利 |

### 招三：感受市场风格切换

| 信号 | 含义 | 动作 |
|------|------|------|
| 连板高度突破前期压制 | 连板行情回归 | 切换打板模式 |
| 中位股连续负反馈 | 题材可能切换 | 减仓观望 |
| 批量大屁股直线拉板 | 市场风格在变 | 重新评估策略 |
| 核心股持续负反馈 | 该题材逻辑可能伪证 | 果断离场 |

## 9.3 量化时代的生存铁律

1. **先手永远赚后手的钱**
2. **T+1制度下散户永远落后量化一步**
3. **放弃盘中的各种"诱惑"** — 看起来很美的拉升很可能是量化在造局
4. **要么找极致的冰点试错，要么找确定性的突破点猛干**
5. **盛极必衰，衰极必盛是市场定律**

# 第十篇：交易纪律

## 10.1 仓位铁律

| 周期 | 仓位 |
|------|------|
| 主升期 | 8-10成 |
| 回暖期 | 3-5成 |
| 混沌期 | 0-3成 |
| 退潮期 | 0（强制空仓）|
| 低位试错期 | 1-3成（冰点可5成）|

## 10.2 行为纪律

> 管住手和止损比技术更重要。

**账户毁灭的根源：**
- ❌ 炸板走弱了还加仓
- ❌ 连续大阴线还补仓
- ❌ 看研报、找基本面给自己做心理按摩
- ❌ 明明该走不走，该认不认

**交易口诀：**
- 买入前："是不是超预期？是不是确定性？"
- 持有时："如果我现在手里没有它，我会不会买它？" 会→持有，不会→走人
- 卖出三档：超预期→等涨停 / 符合预期→持有观察 / 不及预期→竞价走

**知行合一：**
- 只做盘前策略内的标的
- 错过不上后排补救
- 做好盘前策略，不符合就空仓

## 10.3 全周期核心禁忌

1. 只做龙头，不做杂毛
2. 有总龙不做分支龙，有连板龙不做反包龙
3. 退潮期不做中位股
4. 不主观预判龙头（龙头是市场选出来的）

6. 加速期不追缩量板
7. 分歧期不提前切中位
8. 反包期不重仓博弈
9. 退潮期不抄底跟风龙
10. 中位穿越九死一生，切勿盲目博弈

# 第十一篇：强弱研判 — 趋势比当下更重要

> 来源：龙空龙（十五）

## 11.1 核心认知

强弱研判的关键，不是"当下谁封板快、谁封单大"，而是"**谁在走上升趋势，谁在走下降趋势**"。

## 11.2 三个维度研判强弱

| 维度 | 真强 | 假强 |
|------|------|------|
| **趋势** | 涨停时间、封单量、板块带动性一天比一天强 | 一天比一天弱，分歧越来越大 |
| **封单/量能** | 分歧日回封，封单量逐步上升，承接有力 | 连续一字加速，封单量逐步下降 |
| **位置** | 低位分歧回封板，封单变强 | 高位加速一字板，封单变弱 |

## 11.3 避坑三要点

1. **别只看涨停时间，要看趋势变化** — 一字板封得早未必真强，回封时间提前未必真弱
2. **别迷信巨量封单，要看封单变化** — 封单量一天比一天少就是预期走弱信号
3. **别在高位追"强"，要在低位找"趋势"** — 真正的龙头在分歧中一步步走强，最后卡位出来

# 第十二篇：天时地利人和 — 三维共振体系

> 来源：龙空龙（十一）

## 12.1 三维定义

| 维度 | 含义 | 核心 |
|------|------|------|
| **天时** | 情绪周期节点 | 低位试错期小仓布局，主升阶段重仓出击，退潮期坚决空仓 |
| **地利** | 题材强度 | 大题材承载周期（逻辑硬+体量足+持续性强），小题材仅作试错 |
| **人和** | 资金合力 | 放量换手封板是共识体现，板块联动是合力延伸 |

## 12.2 共振策略

| 共振情况 | 操作策略 |
|----------|----------|
| **三者兼备** | 必然盈利，重仓格局，直到周期结束、龙头地位被替代 |
| **三者占二** | 大概率盈利，小仓试错，不可盲目重仓 |
| **三者皆无** | 坚决回避，空仓防守 |

## 12.3 持仓龙头格局心法

> 只要周期未结束、龙头地位未被替代，即可坚定格局。
> 短期分歧、小幅回调只是良性洗盘，无需过分担忧。
> 但如果周期已进入退潮期，或龙头地位被替代，资金合力消散，必须果断离场。

# 第十三篇：每日复盘体系

> 来源：龙空龙（二十）

## 13.1 完整复盘流程（每日照做）

1. **看题材涨幅榜** — 锁定连续走强、容错率最高的核心板块
2. **看涨停梯队** — 梳理炒作逻辑、身位、换手、正宗度
3. **筛选次日可接力标的** — 区分强预期、弱预期、淘汰标的
4. **重点盯** — 板块分歧日依然抗住、依然走强的标的，未来大概率是新龙
5. **锁定龙头后** — 断板减仓、不跌停滚动做T，完整吃满周期行情

## 13.2 复盘核心判断

| 判断项 | 标准 |
|--------|------|
| **持续性** | 连续两日发酵 + 第二天稳定2板梯队 + 第三天继续晋级 = 真持续性 |
| **主线** | 资金认可度最高、持续性最强、容错率最高的核心题材 |
| **情绪** | 通过涨跌家数、炸板率、昨日涨停溢价、昨日跌停负反馈判断 |
| **周期** | 退潮→冰点→修复→发酵→主升→分歧→混沌，不同周期不同仓位 |

## 13.3 盘中突发消息应对

> **突发消息炒作，优先做资金记忆、优先做辨识度老龙。**

大题材炒作，永远是老龙先动、辨识度优先。不管是板块分歧还是突然利好，先动的往往是核心个股。

# 第十五篇：一进二量化策略 — 聚宽实盘验证

> 来源：聚宽量化社区「小蚂蚁i」一进二打板策略
> 实盘成绩：**26年回撤仅10%，收益100%+**
> 核心思路：将龙空龙理论转化为可量化的卡控条件，用数据过滤不确定性

---

## 15.1 一进二完整流程

```
每天盘前（9:05执行）
  ↓
① 获取昨日涨停首板列表
  ↓
② 排除前日/前前日曾涨停的票（剔除连板，只做一进二）
  ↓
③ 四层过滤：均价涨幅→成交额→市值→左压
  ↓
④ 竞价确认：竞价量比 + 高开幅度
  ↓
⑤ 大盘择时：上证开盘跌超1%则全天不买
  ↓
⑥ 分仓买入：最多3只，每只1/3仓位
  ↓
⑦ 两段卖出：11:28有利润就跑 / 14:50不涨停清仓
```

---

## 15.2 选股四层过滤（盘前9:05）

### 第一关：均价涨幅 ≥ 6.5%

```
前日均价涨幅 =（前日成交额 ÷ 前日成交量 ÷ 前日收盘价 × 1.1）- 1
```

> ❌ 不满足 → 淘汰。均价涨幅反映昨日封板的**平均筹码成本分布**，<6.5%说明封板不坚决，资金成本分散。

### 第二关：成交额守门 3亿-25亿

| 条件 | 阈值 | 逻辑 |
|------|------|------|
| 下限 | **≥ 3亿** | <3亿太冷门，无资金关注，次日无接力 |
| 上限 | **≤ 25亿** | >25亿太热门，市场透支，次日溢价有限 |

> 聚宽策略验证：3-25亿区间是首板次日溢价最高的"黄金区间"。

### 第三关：市值过滤器

| 条件 | 阈值 | 逻辑 |
|------|------|------|
| 总市值 | **≥ 70亿** | 太小易被控盘操纵，涨停无技术含量 |
| 流通市值 | **≤ 520亿** | 太大无法连板，资金撬不动 |

### 第四关：左压（左侧压力）— 独创核心概念

**定义：** 当前涨停价左侧有多少个交易日没有更高的价格出现。

```
左压天数 = 从昨天往前找，找到第一个高点≥昨日收盘价的天数 + 5
```

**实战含义：**
- 左压天数越大 → 上方无套牢盘 → 拉升阻力越小
- 左压天数太小 → 刚刚创新高 → 上面有近期套牢盘等着解套

**量能确认：**
```
昨日成交量 必须 > 左压期间最大成交量 × 0.9
```

> ❌ 昨日量能不及左压最大量 → 说明涨停未能消化套牢盘抛压 → 淘汰

**简化记忆：**
> **左压 = 筹码干净度评分。左压长+量能盖过=上方无压力；左压短+量不足=上方有雷区。**

---

## 15.3 竞价确认（9:25）

通过四层过滤后，进入最关键的竞价确认：

### 条件一：竞价量比 ≥ 2.5%

```
竞价量比 = 集合竞价成交量 ÷ 昨日全天成交量
```

| 竞价量比 | 判断 |
|----------|------|
| ≥ 5% | ✅ 极强，资金抢筹激烈 |
| 2.5%-5% | ✅ 合格，资金关注度高 |
| < 2.5% | ❌ 淘汰，竞价无资金关注 |

> ⚠️ 这是和现有竞价体系（8%-10%）的关键区别：一进二策略用的是**2.5%绝对值**，因为首板票还不算龙头，竞价量不会太大。现有体系的8%-10%标准针对的是**已确定的身位龙**。

### 条件二：高开幅度 > 1%

```
竞价价 / 昨日收盘价涨停价（昨收×1.1）> 101%
```

**翻译：**竞价价必须高于昨日收盘价，即必须高开。

```
竞价价 > 昨收 × 1.1 × 1.01 = 昨收 × 1.111
```

> ❌ 平开或低开直接淘汰。一进二必须高开确认溢价预期。

### 竞价确认总流程

```
竞价量比 ≥ 2.5%？ → ✅ → 高开 > 1%？ → ✅ → 进入买入池
       ↓ ❌                    ↓ ❌
      淘汰                    淘汰
```

## 15.4 大盘择时（买入前最后一道防线）

```
上证指数 开盘涨幅 < -1% → 今日不买入，直接return
```

> 大盘开盘就暴跌1%以上，市场恐慌情绪蔓延，此时首板次日溢价概率极低。宁可错过不可做错。

## 15.5 仓位与买入规则

| 规则 | 内容 |
|------|------|
| **最多持仓** | 3只 |
| **单只仓位** | 总资金 ÷ 3（≈33%） |
| **买入时机** | 9:28 开盘前以竞价价买入 |
| **单笔门槛** | 单只股票买入金额 > 100股的金额 |

> **核心思想：** 一进二是概率游戏，分仓分散风险。即使2只失败1只成功，总账也是赚的。

## 15.6 两段卖出规则

### 卖出点一：上午11:28 — 有利润就跑

```
条件：持有股票未涨停 + 当前价 > 成本价
动作：全部卖出
```

> **逻辑：** 上午快收盘还没涨停，说明今天不太可能连板。有利润就落袋，别等下午跳水。

### 卖出点二：下午14:50 — 不涨停清仓

```
条件：持有股票未涨停（不管盈亏）
动作：全部卖出
```

> **逻辑：** 距离收盘只剩10分钟还不涨停，今天没有二板希望。即使亏损也走，不持有过夜。

### 卖出规则速查

| 时间 | 条件 | 动作 |
|------|------|------|
| **11:28** | 未涨停 + 有利润 | ✅ 全部止盈 |
| **11:28** | 已涨停 → 不动 | ⏸️ 继续持有 |

| **14:50** | 已涨停 → 不动 | ✅ 拿二板过夜 |

## 15.8 一进二与其他策略的协同

### 与龙头体系的区别

| 维度 | 一进二量化 | 龙头战法 |
|------|----------|----------|
| 目标 | 首板 → 二板的概率博弈 | 确认龙头后的主升浪 |
| 仓位 | 分仓3只（概率分散） | 重仓1只（确定性集中） |
| 竞价要求 | 量比≥2.5%即可 | 5%-10%甚至更高 |
| 持有时间 | 最多1天（当天不板就走） | 3-5天甚至更久 |
| 适用周期 | 启动期/试错期 | 主升期/确认期 |
| 回撤控制 | 分仓+两段止损 | 仓位纪律+止盈纪律 |

### 何时用一进二 vs 龙头战法

| 周期阶段 | 首选策略 | 仓位 |
|----------|----------|------|
| **低位试错期** | 🆕 **一进二量化** | 1-3成（分3只） |
| **主升期** | 龙头战法（重仓龙头） | 5-10成 |
| **混沌期** | 一进二量化（小仓试错） | 0-3成 |
| **退潮期** | 两个都不用，空仓 | 0 |

> **一进二是试错期的标准执行策略。** 旧龙头刚断板，新龙头还没出来，用一进二量化卡控去"海选"首板中最有可能晋级二板的标的，概率博弈取胜。

## 15.9 每日一进二复盘检查

盘后（15:01执行）：
1. **昨日涨停首板**有多少只？→ 通过四层过滤的有几只？
2. **竞价确认**成功率？→ 量比和高开过滤掉了多少？
3. **最终买入的股票**今日结果？→ 涨停/炸板/未板各几只？
4. **晋级成功但未买入**的股票有哪些？→ 被哪个过滤条件淘汰的？为什么？（这是复盘最核心的价值——找到过滤条件是否太严/太松）
5. **11:28卖出**的股票下午表现如何？→ 验证"有利润就跑"是否正确

> 复盘目标不只是看赚赔，而是**不断优化过滤条件**，让策略越来越精准。
