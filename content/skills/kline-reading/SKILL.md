# K 线读图

读图的顺序比结论重要。顺序错了，任何形态都能找到两种解释。

## 适用场景

- 需要判断某只股票当前处于什么位置、有没有可执行的失效位。
- 盘前候选池筛选（`premarket-plan` 第 5 步）。
- 量化策略的信号复核：形态是否与代码算出来的一致。

不适用：判断公司价值（看财报与行业），以及判断消息真假（看公告）。

## 前置检查

| 检查项 | 怎么查 | 不通过时的动作 |
|---|---|---|
| 复权口径统一 | `market.bars` 的 `adj` 参数（`qfq`/`hfq`/空） | 同一组对比必须同口径；跨除权日必须用复权 |
| 数据条数够 | `limit` ≥ 120 根日线 | 少于 60 根不判断趋势 |
| 最后一根已收盘 | K 线日期 < 今天，或今天已过 15:00 | 未收盘的当根不能参与形态判断 |
| 代码与市场正确 | 6 位代码 + `sh`/`sz`/`bj` 前缀 | 张冠李戴是最常见的低级错误 |

## 步骤

### 1. 先定周期，再看图

固定三层，不要跳：

- **周线定方向**：最近 20 周均线方向、周线是否连阴；
- **日线定结构**：20 / 60 日均线排列、前高前低位置；
- **60 分钟定节奏**：最近 2–3 天的分时结构，用于择时。

同一结论必须在两个周期上不矛盾。周线下跌、日线突破，只能算反弹。

### 2. 判位置：三个百分比

对每只标的算三个数，写进结论：

- 距 60 日最高：`(现价 - 60日最高) / 60日最高`；
- 距 60 日最低：`(现价 - 60日最低) / 60日最低`；
- 距 20 日均线：`(现价 - MA20) / MA20`。

位置决定容错：距高点 < 3% 的位置，止损空间被压缩，任何形态的成功率都下降。

### 3. 判量能：量比与额比

```
额比 = 当日成交额 / 前 5 日平均成交额
```

| 额比 | 判定 | 含义 |
|---|---|---|
| < 0.8 | 缩量 | 分歧收敛，回调可能结束，也可能无人接 |
| 0.8–1.2 | 平量 | 无信息 |
| 1.2–2.0 | 温和放量 | 有资金参与，需要看方向 |
| > 2.0 | 显著放量 | 分歧放大，方向由收盘位置决定 |

量能必须与位置一起读：高位放量滞涨是风险，低位放量长阳是启动的第一根证据。

### 4. 判形态：只认六种组合

单根 K 线不足以构成结论，组合才有效。日常只需识别：

1. **长上影 + 放量**：上方抛压重，次日多数回落（需次日确认）。
2. **长下影 + 放量**：下方有承接，位置在低位时有效。
3. **十字星 + 缩量**：变盘前夜，等次日方向。
4. **阳包阴 / 阴包阳**：一根吃掉前一根实体，方向反转的最小证据。
5. **连续两根缩量小阴**：上涨中继的概率高于见顶。
6. **跳空缺口**：缺口不回补，说明趋势强；三日不回补视为有效。

不要数"三只乌鸦""红三兵"这类命名，只说**实体、影线、量能**三件事。

### 5. 找失效位（这是唯一必须给的数）

失效位 = 一旦跌破/突破，这个判断就错了的价格。取法：

- 上涨结构：取最近一根放量阳线的开盘价，或最近一个有效低点；
- 下跌结构：取最近一根放量阴线的开盘价；
- 震荡结构：取区间边界，不做单边判断。

失效位必须是**结构位**，不能取整数关口或"跌 5%"。

### 6. 写结论，格式固定

一条结论只写四行，缺一行不算完成：

```
趋势：日线在 20/60 日均线上方，周线连阳 3 周 → 多头
位置：距 60 日最高 -1.8%，距 MA20 +4.2% → 偏高
量能：额比 1.35，收盘在实体上 1/3 → 温和放量收强
失效：跌破 12.40（最近放量阳线开盘价）→ 判断作废
```

## 输出模板

```markdown
## K 线判读：600xxx（日线，前复权 qfq）

- 数据区间：2026-05-12 ~ 2026-11-10，共 130 根
- 周线方向：MA20 上行，最近 3 周连阳
- 日线排列：收盘 > MA20 > MA60，多头排列
- 位置：距 60 日最高 -1.8%，距 60 日最低 +18.4%
- 量能：额比 1.35（5 日均额 3.1 亿 → 当日 4.2 亿）
- 形态：昨日阳线实体吃掉前一日阴线实体，收在最高价附近
- 失效位：12.40（放量阳线开盘价）
- 结论：多头结构，位置偏高，容错空间 4.4%
```

## 常见错误

1. **不复权看历史**。除权日前后价格不连续，形态全是假的。
2. **用未收盘的当根做判断**。盘中 14:00 的"长上影"到 15:00 可能是长下影。
3. **只看日线不看周线**。日线突破在周线下跌趋势里，成功率显著下降。
4. **把单根大阳当趋势**。趋势需要均线排列与连续量能支撑。
5. **形态命名代替描述**。"早晨之星"没法校验，实体与影线长度可以。
6. **失效位取整数**。整数关口是全场共识，被扫的概率最高。
7. **跨周期混用**。周线结论套 5 分钟图执行，时间尺度不匹配。

## 禁止事项

- 不预测具体点位与时间。
- 不用形态计算"目标价"。
- 不忽略停牌、除权、重大公告对 K 线连续性的破坏。
- 不把 K 线结论当买卖建议输出。
- 不在样本少于 60 根时给趋势判断。
