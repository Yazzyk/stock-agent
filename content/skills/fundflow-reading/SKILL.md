# 资金流解读

资金流是**按成交额分档统计的推断**，不是真实的账户交易记录。口径不说清，数字就会骗人。

## 适用场景

- 判断某只股票当日/近几日的资金方向（`flow.stock`）。
- 判断行业或概念的资金强弱（`flow.rank`、`sector.list`）。
- 复核一个"资金流入所以看多"的说法是否站得住。

不适用：判断长线资金（公募、外资持仓看季报与互联互通数据），以及判断单一主力身份。

## 前置检查

| 检查项 | 怎么查 | 不通过时的动作 |
|---|---|---|
| 单位一致 | 新浪返回单位为**元** | 展示统一换算成亿元，保留 2 位 |
| 分档口径 | 见下表 | 混用不同数据商的分档，结论不成立 |
| 数据完整 | 收盘后刷新才是当日最终值 | 盘中取到的是滚动值，标注"盘中值" |
| 板块归属 | `sector.list` 返回的最新成分 | 概念归属有滞后，标注更新时间 |

## 口径（唯一真源，与 docs/DOMAIN.md 第 2 节一致）

个股当日资金流走新浪 `MoneyFlow.ssi_ssfx_flzjtj`，`r0`~`r3` 四档各给买入额与卖出额：

| 档位 | 上游字段 | 净额 | 说明 |
|---|---|---|---|
| 超大单 | `r0_in` / `r0_out` | `r0_net = r0_in − r0_out` | 分档门槛由新浪定义 |
| 大单 | `r1_in` / `r1_out` | `r1_net = r1_in − r1_out` | 同上 |
| 中单 | `r2_in` / `r2_out` | `r2_net = r2_in − r2_out` | 同上 |
| 小单 | `r3_in` / `r3_out` | `r3_net = r3_in − r3_out` | 同上 |
| 主力净额 | — | `r0_net + r1_net` | 与旧东财「超大单 + 大单」同名口径等价 |

- `r0`~`r3` 的 `*_in` / `*_out` 是**成交额**，净额 = `in − out`，必须自己做差。
- 单位：**元**。展示统一换算成亿元，保留 2 位。
- **多日序列口径更窄**：`ssl_qsfx_zjlrqs` 只给 `r0_net`、`netamount`、`turnover`、`changeratio`，所以多日的「主力」是**超大单净额**，比当日的「超大 + 大」更窄。两条曲线不要画在一张图上比大小。
- **板块榜又是另一种口径**：`ssl_bkzj_bk` 的 `netamount` 是板块**全部资金净额**，不分主力/散户；和个股主力净额只能比方向，不能比金额。

**必须知道的三件事**：

1. 分档按**单笔成交额**，与账户大小无关。一个大账户拆单，会被算成中单。
2. 主动买入与主动卖出按**逐笔成交方向**判定，集合竞价的成交归属不规范。
3. 主力净流入为正，不代表股价会涨：它只说明大单的主动买入多于主动卖出。

## 步骤

### 1. 先写口径，再写数字

每次输出资金流结论，开头必须写一行：

```
口径：新浪 r0_net + r1_net（超大单 + 大单净额），单位元，数据截至 2026-11-10 15:00
```

没写口径的数字，不可复核。

### 2. 个股层：看三日，不看一日

`flow.stock` 取最近 5 个交易日的 `mainNet`（当日口径 = 超大单 + 大单净额）。判定规则：

- 连续 3 日净流入且金额递增 → 资金持续介入；
- 单日大额净流入但前后均为净流出 → 一日游，不作为依据；
- 净流入占成交额比例 < 1% → 噪声级别，忽略。

比例算法：`mainNet / amount`（成交额同口径）。1% 以下的净流入在实证上不具备区分度。

### 3. 板块层：验证个股是否被板块解释

`flow.rank`（行业）与 `sector.list`（概念）取当日与近 5 日排名。注意板块榜是**板块全部资金净额**，个股是主力净额：两者只能比方向，不能比金额。

- 个股净流入 + 板块净流入：同向，个股判断有板块支撑；
- 个股净流入 + 板块净流出：个股是板块内的少数派，持续性弱；
- 个股净流出 + 板块净流入：个股被板块内其它标的抽走资金，警惕。

板块排名每天变化剧烈，近 5 日累计排名比单日排名可信。

### 4. 大盘层：确认不是整体放水

指数主力净额与两市成交额决定"资金是否整体在进"。

- 两市成交额缩量 + 个股净流入：存量博弈里的结构行情；
- 两市成交额放量 + 个股净流出：普涨里被抛弃的标的，风险更高。

### 5. 三层一致性结论

只有三层同向时，才给"资金面支持"的判断。任一层反向，标记为"分歧"，只记录不采信。

### 6. 剔除口径噪声

下列情形的资金流数字要单独说明，不能直接入结论：

| 情形 | 为什么失真 | 处理 |
|---|---|---|
| 大宗交易 | 不计入逐笔主动买卖统计 | 单独看大宗折溢价 |
| ETF 申赎与成分调整 | 被动买卖被算成大单 | 查当日有无指数调整公告 |
| 新股上市前 5 日 | 无涨跌幅限制，波动极端 | 不参与板块均值 |
| 停牌复牌首日 | 集中成交，方向由挂单堆积决定 | 只记录不判断 |
| 涨跌停封板 | 封单不计入主动成交 | 用封单量与排队资金判断 |

### 7. 板块归属的滞后

概念与行业成分由数据商维护，个股调入调出有 1–3 个交易日滞后。写结论时必须带一句"板块成分更新至 <日期>"。

一只股票可同时属于多个概念板块。用板块解释个股时，取**该股成交额最大的那个板块**，不要挑最符合结论的那个。

## 输出模板

```markdown
## 资金流判读：600xxx

- 口径：新浪 r0_net + r1_net（超大单 + 大单净额），单位元，数据截至 2026-11-10 15:00
- 个股近 5 日主力净额：+1.2 亿 / +0.8 亿 / -0.3 亿 / +1.9 亿 / +2.4 亿
- 净流入占成交额：2.4 / 4.2 亿 = 5.7%（高于 1% 噪声线）
- 板块（半导体，成分更新至 2026-11-08）：当日 +18.6 亿，近 5 日累计 +42.1 亿，排名 1/86
- 大盘：两市成交额 1.86 万亿（较 5 日均 +9%），指数主力净额 +210 亿 → 整体放量流入
- 一致性：个股、板块、大盘三层同向
- 结论：资金面支持，但需注意个股当日已属板块内净流入前 10%，位置偏高
- 噪声说明：当日无大宗交易与指数调整
```

## 常见错误

1. **把主力净流入等同于"有人买"**。它只统计主动成交方向，拆单与被动成交都看不见。
2. **只看单日数字**。单日净流入的次日延续性很差，至少看 3 日。
3. **不做比例换算**。2 亿净流入在成交额 80 亿的票里是噪声，在 8 亿的票里是重仓信号。
4. **用板块资金流反推个股**。板块均值掩盖个股分化，必须两层都看。
5. **忽略分档口径**。不同数据商门槛不同（有的按 50 万/10 万），横向比较前先统一。
6. **把涨跌停封单当流入**。封板期间主动成交极少，资金流数字几乎为零。
7. **拿概念板块当行业板块**。概念有重叠、有人工标注、有滞后。

## 禁止事项

- 不写"主力进场所以会涨"这类因果断言。
- 不用资金流单指标生成买卖信号。
- 不省略口径说明。
- 不把不同数据商的资金流数字混在一张表里比较。
- 不对单日异常数字（> 成交额 20%）直接采信，先查公告与大宗。
