# 量化诚实性检查

回测的第一产出不是收益率，是**这份结论能不能被相信**。下面五关，任选其一不过，结论作废。

## 适用场景

- `quant.backtest` 跑完，准备写 `report.md`。
- 看到某个策略年化 80%，需要判断是策略还是 bug。
- 参数调优后，要判断是不是过拟合。

不适用：单笔交易的复盘（用 `postmarket-review`）。

## 前置检查

| 检查项 | 怎么查 | 不通过时的动作 |
|---|---|---|
| 数据区间与频率 | 回测配置里的起止日期、周期 | 区间 < 2 年或 < 250 根日线，结论不稳定 |
| 复权口径 | 全程同一 `adj` | 中途换口径等于换了数据 |
| 股票池是否含退市 | 池子构建方式 | 只含现存股票 → 幸存者偏差，见第 4 关 |
| 成本参数 | 见下表 | 零成本回测的数字不作数 |

## 成本口径（唯一真源，与 docs/DOMAIN.md 第 5 节一致）

| 项目 | 参数 | 生效说明 |
|---|---|---|
| 佣金 | 双边 0.03%，单笔最低 5 元 | 券商差异大，最低 5 元按笔计 |
| 印花税 | 卖出 0.05% | 2023-08-28 起由 0.1% 减半 |
| 过户费 | 双边 0.001% | 2022-04-29 起沪深统一 |
| 滑点 | 单边 0.1% | 与流动性相关，小市值需上调 |

**每笔往返成本下限**：0.03% × 2 + 0.05% + 0.001% × 2 + 0.1% × 2 ≈ 0.26%。加上最低 5 元佣金，小额交易的边际成本更高。

年换手 20 次的策略，成本约吃掉 5.2% 年化。这是很多"高收益策略"消失的地方。

## 步骤

### 1. 第一关：未来函数

逐条核对实现，不看文档看代码：

- 决策用的是第 `i` 根 K 线的收盘价，成交必须在第 `i+1` 根（开盘或均价），不能同日成交；
- 指标计算窗口是否包含当根（`SMA` 用 `close[i-period+1:i+1]` 是正确的，用 `close[i-period+1:i+2]` 就是泄漏）；
- 是否用了当日最高/最低价做触发（盘中不可知）；
- 财务数据是否用"最新一期"回填历史（point-in-time 问题，最隐蔽的一类）；
- 涨跌停日是否假设能成交（涨停买不进、跌停卖不出）；
- 是否用了当日成交额、当日资金流决定当日动作。

**判定**：任意一条成立 → 标注"存在未来函数"，所有绩效数字加 ❌，不出结论。

### 2. 第二关：样本内外

把区间切成前 70% / 后 30%：前段只用于选参，后段**只验证一次**。

- 后段必须与参数选择完全隔离（选参过程不得读取后段数据）；
- 后段样本量 ≥ 60 笔交易，否则不构成检验；
- 输出样本外 / 样本内的收益比。

**判定**：样本外收益 < 样本内 50% → 过拟合。这不是失败，是本项目最有价值的产出。

### 3. 第三关：walk-forward

滚动窗口：每段训练 N 年、验证 M 月，逐段独立选参、独立验证，把各验证段拼接成净值曲线。

- 至少 4 段，少于 4 段不叫 walk-forward；
- 每段参数允许变化，记录参数漂移；
- 拼接净值要扣掉每段的成本。

**判定**：拼接净值年化为负，或段间参数跳变幅度 > 50% → 策略不稳定。

### 4. 第四关：幸存者偏差

股票池必须是**当时可得**的股票集合：

- 含已退市、已更名、被借壳的标的；
- 指数成分用历史成分，不用今天的成分回溯；
- 新股上市前 5 日（无涨跌幅限制）单独处理。

**判定**：池子只含现存股票 → 收益被系统性高估，尤其在小市值策略上。

### 5. 第五关：参数敏感性

对每个参数做邻域扫描（±1 档）：

- 邻域内绩效平滑下降 → 参数稳健；
- 邻域内某一格突然最优、旁边崩塌 → 曲线拟合；
- 最优参数落在扫描边界 → 真实最优可能在界外，扩范围重跑。

**判定**：参数邻域内绩效标准差 > 均值的 50% → 参数脆弱，不可实盘化（研究结论也要标注）。

### 6. 写报告：五关结论前置

`report.md` 的第一节必须是自检表，绩效数字在后面。顺序反了，读者会先看收益再看风险。

## 输出模板

```markdown
# 回测报告：ma_cross / 沪深 300 成分（历史成分）

## 一、诚实性自检

| 关卡 | 结论 | 证据 |
|---|---|---|
| 未来函数 | 通过 | 信号用 T 日收盘，T+1 开盘成交；指标窗口不含未来；财务数据用公告日 |
| 样本内外 | 不通过 | 样本内年化 21.4%，样本外 8.1%，衰减 62% |
| walk-forward | 不通过 | 4 段中 2 段年化为负 |
| 幸存者偏差 | 通过 | 池含退市 37 只，用历史成分 |
| 参数敏感性 | 通过 | 邻域 ±1 档年化在 7.8%–9.2% 之间 |

**结论：样本内外衰减 62%，超过 50% 阈值，判定为过拟合，不进入候选池。**

## 二、绩效（仅供参考，已被自检否决）

- 区间：2019-01-02 ~ 2025-12-31（1700 交易日）
- 总收益 +182%，年化 18.1%，最大回撤 -31.4%，夏普 0.82
- 交易 412 笔，胜率 48.3%，盈亏比 1.42

## 三、成本明细

- 佣金 0.03%×2（最低 5 元）、印花税 0.05%（卖出）、过户费 0.001%×2、滑点 0.1%×2
- 往返成本约 0.26%/笔，年换手 18 次 → 年成本约 4.7%

## 四、已知缺口

- 涨跌停日的成交假设仍偏乐观（假设次日开盘可成交）
- 未做行业中性化，收益可能来自行业暴露而非择时
```

## 常见错误

1. **先看收益再看代码**。顺序反了，会为高收益找理由。
2. **同日收盘决策同日收盘成交**。最经典、最容易漏的未来函数。
3. **零成本或只算佣金**。印花税与滑点常被漏掉，年化差 3–5 个点。
4. **样本外只用一次**。调参后反复看样本外，样本外就变成了样本内。
5. **指数用当前成分回溯**。十年回测里活下来的公司天然更强。
6. **参数只报最优点**。不报邻域，等于隐藏了脆弱性。
7. **用总收益评价策略**。不看回撤与换手，收益无法比较。

## 禁止事项

- 不自检就出结论。
- 不隐藏负结果：样本外衰减必须写在报告第一节。
- 不把"历史最优参数"当未来参数。
- 不用单一指标（夏普/胜率）代替完整评估。
- 不对未通过自检的策略做任何实盘化暗示。
