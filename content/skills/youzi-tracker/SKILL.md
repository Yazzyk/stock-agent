# 游资分析 Skill (youzi-tracker)

## 概述

专业A股游资席位追踪与龙虎榜分析工具。识别知名游资的操盘手法，追踪席位动向，解读资金博弈格局，为短线交易提供情绪面和资金面的参考。

## 分析流程

### 步骤1：获取数据

```python
import akshare as ak

# 1. 当日龙虎榜明细
df_lhb = ak.stock_lhb_detail_em(start_date='20260710', end_date='20260710')

# 2. 近一月营业部排名（找活跃游资）
df_trader = ak.stock_lhb_traderstatistic_em(symbol='近一月')

# 3. 重点营业部详细记录
df_yyb = ak.stock_lhb_yyb_detail_em(symbol='10045025')  # 溧阳路
```

### 步骤2：游资识别

在龙虎榜明细中，根据营业部名称匹配知名游资席位库：

1. 提取龙虎榜明细中的买方/卖方营业部
2. 与游资席位库进行关键词匹配
3. 标记哪些个股有知名游资参与

### 步骤3：资金博弈分析

对于每只上榜个股：
- **净买额方向**：游资净买入 vs 机构净买入
- **席位协同**：多个知名游资同时买入（合力做多）
- **席位对立**：买方游资 vs 卖方游资（分歧）
- **买卖比**：龙虎榜买入额/卖出额，>2 看多，<0.5 看空

### 步骤4：后市表现评估

利用龙虎榜数据自带的"上榜后N日"字段：
- 上榜后1日、2日、5日、10日涨跌幅
- 判断游资的胜率和持股周期

### 步骤5：综合研判

| 维度 | 权重 | 判断标准 |
|------|------|----------|
| 游资参与度 | 30% | 知名游资数量、席位质量 |
| 资金方向 | 25% | 净买额/成交比、买卖比 |
| 席位协同 | 20% | 合力/分歧 |
| 机构态度 | 15% | 机构买入/卖出对比 |
| 历史胜率 | 10% | 该游资近期成功率 |

## 工具脚本

分析工具脚本存放在 `tools/youzi_analysis.py`，提供：

1. **`analyze_daily_lhb(date)`** - 分析指定日期的龙虎榜，识别游资
2. **`track_trader(trader_code, days=30)`** - 追踪指定游资近期操作
3. **`top_active_traders(days=30)`** - 近期最活跃游资排名
4. **`stock_lhb_history(stock_code, months=3)`** - 个股龙虎榜历史

## 风险提示

- 游资操作具有高度投机性，跟风风险极大
- 龙虎榜数据滞后一日，游资可能已出货
- 席位可能更换，需持续维护席位库
- **所有分析仅供参考，不构成投资建议**
